01
Why this

一個問題：能量去哪了？

現代人不缺工具，缺的是看懂自己此刻狀態的一面鏡子。你累，但說不清是空了、太滿、還是卡住；你想改變，卻不知道該推哪一顆按鈕。

練息場的假設很簡單：把人的內在，拆成 8 種可辨識的能量功能，再對照當下處境所要求的能量，就能給出一句具體、可行動的下一步——而不是一個命定的標籤。

易，窮則變，變則通，通則久。 ——《易經・繫辭下》
三種「累」，三條路。
空了 生理耗竭 → HRV / 恢復
太滿 過載 → 界線工具
卡住 卡在某功能 → 八態調節

練息場不急著給答案，先幫你分流到對的地方——工具、練習，或真人老師。

02
The core model

雙層模型：你，與你的處境

整個平台建立在兩層之上。它們不競爭，而是分工——一層描述穩定的你，一層描述流動的處境。

卦層 · Situation Layer

問易・卜易 — 你在什麼處境

用 64 卦讀「當下這件事在要求什麼」。每一卦標明它召喚哪些功能、要你節制哪些功能。隨時變動——同一個問題，不同時刻，可能是不同的卦。

▲　疊加　▼
底層 · Ground Layer

八態能格 — 你是誰

你穩定的能量基線：8 種功能裡，你慣用哪些、哪些還沒長開，各自是「過用／適中／不足」。相對穩定，是你回應世界的工具箱。

皇冠時刻 — 橋接（Route B）：問易告訴你「處境要什麼」，八態告訴你「你最能怎麼回應」。同一卦、不同人、不同建議。這是「課題分離」：處境你選不了，但怎麼接，是你的。
03
Theory stack

四層堆疊：科學 × 感覺

層 A

HRV 生理錨點

心率變異度，把「我是不是空了」變成可量測的生理訊號。感覺之外，給一個客觀的底。

層 B

八態能格

8 功能的自我覺察系統，根植易學、面向現代語言。回答「你是誰、怎麼被配置」。

層 C

問易・64 卦

讀處境的結構化決策支持，扎根古典文本，應用於眼前的生活。回答「此刻在要求什麼」。

層 D

能量小幫手

前門分流工具：「你在哪個狀態？下一步往哪走？」把疲累的使用者接到對的資源。
