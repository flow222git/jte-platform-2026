# HRV Tool i18n (zh/en/ja) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add zh-default / en / ja multi-language support to `hrv/index.html` using the platform's `jte-i18n.js` engine, covering intro / measure / result / trend views.

**Architecture:** Load `jte-i18n.js` via absolute CDN URL (hrv is a subfolder). Define `window.JTE_I18N` with en/ja dictionaries before the script. Replace all display-string literals in JS render functions with `jteT('key','中文原文')`. Implement `window.jteI18nApply(lang)` to re-render the active view safely (no camera restart for `measure` mode — updateLiveUi already calls jteT each tick). Store last result params in module vars so result view can re-render on lang switch.

**Tech Stack:** Vanilla JS, jte-i18n.js CDN, Python3 + headless Chrome test harness.
