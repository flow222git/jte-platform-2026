## 敘事引擎:確定性,非 AI 主筆

家規「正式報告由規則引擎組裝」不動。敘事總結=模板槽位+canonical 文案庫,
參數全部來自分數的確定性計算:

### 地形判別(整體段的選擇器)

- 水位 = 八態平均:高 >70 / 中 40-70 / 低 <40
- 落差 = 最高-最低:極端 >50 / 起伏 25-50 / 平坦 <25
- 地形 = 峰崖分布:單峰 / 雙峰(雷風=張力) / 多峰無主 / 斷崖(單一極低)

六型與敘事開場:
| 地形 | 開場策略 |
|---|---|
| 斷崖型 | 對比開場——最亮與最空的故事,斷崖是主角 |
| 孤峰型 | 聚光燈開場——一盞燈和它的影子 |
| 群峰型 | 張力開場——幾股力在拉(僅雷風寫「張力」,守 C1) |
| 高原型 | 合唱團開場——沒有主唱;寫切換的自由與帳單 |
| 丘陵型 | 日常開場——寫「哪個先動」不寫「哪個最強」 |
| 湖面型 | 季節開場——水位在收,寫休養不寫匱乏;禁「弱」語法 |

註:「平均」只在高原/丘陵型當主角;斷崖型裡平均是雜訊,不寫。
卡片認出的鑑別度也是地形的函數(高原型必飽和)——卡片模組日後可依地形調整。

### 摘要層定位(2026-07-19 Simon 定調:論文摘要式,敘事即目錄)

敘事總結=**摘要+索引**,不是完整敘事文章:
- **短**:全文 200-300 字,五幕各 1-2 句
- **無詳細數字**:數字住在詳細資料;摘要用水位語(最亮/偏低/斷崖),不出現「99」「7」
- **敘事即索引**:每幕的關鍵句=錨點連結,點了跳到對應詳細段——
  最亮的態→六級列表(定位該態)、斷崖→能格/還沒長開、內部一致→二選一對照、
  亞隆句→你的章節(亢段)、四系統句→系統區塊;詳細段落附「回摘要」
- 完整長敘事(散文版全文)不進 v1 範圍;若日後要,放「伴讀說書」opt-in

### 五幕結構(幕與幕的順序固定,內容由參數選)

1. **最突出的**:最亮的態(+若斷崖,最空的態;落差>50 觸發「斷崖段」)
2. **合起來的樣子**:地形開場(上表)
3. **這份快照有多可信**:FC 二選一與分數的一致性;無篤定資料時誠實註明
4. **如果這是你**(亞隆段):寫他熟悉的時刻,不寫他該怎樣;含一個不討喜的誠實觀察
5. **四個系統,一個故事**:每系統一句敘事,互相呼應(如「同一個訊息出現了兩次」)

收尾:快照非標籤+「哪段最中、哪段最不像,由你裁決」。

### 亞隆 tone 指南(入 material-pool 風格區,所有敘事文案適用)

- 第二人稱+暫定語:「如果這是你」「不是嗎?」——遞出,不宣告
- 寫場景與時刻,不寫抽象特質:「燈熄之後才開始」而非「內向」
- 敢寫不討喜處,但溫柔:「你遞出去的是建議,或背影」
- 旅伴語態,不是專家語態;禁預測、禁標籤、禁罐頭同理
- 收在問句:「你的沉默,對方讀得懂嗎——還是你其實希望他讀不懂?」

### 詩庫(canonical,選用)

- 峰名卡四行詩:八態×主峰各一首;斷崖/雙峰格局加變體
- 報告收尾詩(選用):誠實印章的詩體(「這是七月的水位,不是你的名字」式)
- 全部預寫入 canonical 資料檔,規則選詩填水位;走 material-pool 出貨動線
