## 1. 要做什麼

使用者 2026-11-17：「網站風格我想要兩種並存，可以讓使用者自行選擇使用，現有的跟插畫版的都並存。」

討論後的決定（都在 2026-11-17）：

- **同一個頁面換外觀**，不是兩套頁面。功能、版面、文字只有一套。
- **插畫版以現在 `/me` 整理區的風格為準**：米色紙、蠟筆顆粒、手寫字（取自使用者的速寫本照片），擴大到整頁。不是回到 06 原型那種插畫很多的版本。
- **整個平台都要**，分四段做（見第 2 節）。
- 預設是現在的簡潔版；選擇只記在這台裝置，不需要登入。

這份規格取代主規格 5.2「蠟筆、手寫字、米色紙只用在整理出來的樣子」這一條的適用範圍：在「簡潔」風格下它仍然成立；在「手帳」風格下，整頁都是手帳感。

## 2. 分段

| 段 | 範圍 | 這份規格 |
|---|---|---|
| 1 | 共用基礎：全站共用的風格檔與切換程式 | 涵蓋 |
| 2 | `/me` 我的練息場套用兩種風格 | 涵蓋 |
| 3 | 首頁改用同一套設計並支援兩種風格 | 另寫規格。「現行首頁的日曆何時下架」在這一段決定 |
| 4 | 各工具頁（呼吸覺察、小憩練息、HRV、問易、心情溫度計、書寫、溝通類型測驗）一頁一頁改 | 另寫規格 |

八態能格維持自己的宣紙風格，四段都不動它。要不要跟著換，等前面做完再決定。

每一段做完都可以單獨上線：還沒改的頁面維持原樣，不受影響。

## 3. 考慮過的做法

| 做法 | 內容 | 取捨 | 結果 |
|---|---|---|---|
| A 換一組設定 | 頁面的顏色、圓角、字體已集中成 CSS 變數；`<html data-theme>` 換掉這一組，再加紙質與蠟筆效果 | 一套程式，新功能兩種風格都自動有 | **採用** |
| B 兩份樣式檔互換 | 簡潔、手帳各一份完整 CSS | 兩邊容易不同步，改一處要改兩次 | 不採用 |
| C 每頁各自切換 | 每個頁面自己寫切換 | 到首頁與工具頁會重複很多次 | 不採用 |

## 4. 設計

### 4.1 共用基礎（第 1 段）

兩個檔，放 repo 根目錄，各頁用相對路徑引用（不用外部絕對網址）：

- **`jte-theme.css`**：
  - `:root { … }`：簡潔版的設定（現在 `me/index.html` 裡 `:root` 那一組：色票、圓角、陰影、字體），原樣搬過來。
  - `:root[data-theme="sketch"] { … }`：手帳版覆寫同一組名稱。
  - 手帳版共用的效果（紙質底、蠟筆邊線）以變數與少量通用規則提供，頁面不需要知道細節。
- **`jte-theme.js`**：
  - 在 `<head>` 裡同步執行（不加 `defer`），頁面畫出來之前就把 `data-theme` 設好，不會先閃一下另一種風格。
  - 讀寫 localStorage `jte_theme_v1`，值是 `'simple'` 或 `'sketch'`。讀不到、不認得的值、localStorage 不能用，一律當成 `'simple'`。
  - 介面：`JteTheme.get()`、`JteTheme.set(name)`、`JteTheme.normalize(value)`（純函式）、`JteTheme.mount(element)`（在指定位置畫出切換鈕）。
  - 兩種風格的名稱寫在這個檔裡，全站共讀這一份：`simple` 顯示「簡潔」，`sketch` 顯示「手帳」。
  - 另一個分頁改了風格時（`storage` 事件），這一頁跟著換。

風格偏好不是作答資料，但同樣只存在本機、不上傳。

### 4.2 兩種風格

| | 簡潔（預設） | 手帳 |
|---|---|---|
| 底 | `#F6F8FB`、白卡 | 米色紙，帶細紙紋；卡片是稍淺的紙色 |
| 字 | 源柔黑體，深墨藍 | 標題用手寫字；內文維持源柔黑體，確保好讀；字色偏鉛筆棕 |
| 色塊 | 課程站的粉彩色卡 | 同一組顏色，加蠟筆顆粒 |
| 線與邊 | 細框、淡陰影 | 鉛筆感的邊線，不用陰影 |
| 按鈕與導覽 | 深色膠囊、橘色目前頁 | 手繪感的膠囊，目前頁用蠟筆橘 |
| 整理區（這個月的樣子、生命地圖、使用說明書） | 米色紙、蠟筆、手寫字（現狀） | 不變，與整頁融在一起 |

兩種風格下功能、版面、文字、互動完全相同。對比度、觸控目標大小、`prefers-reduced-motion` 的處理兩邊都要符合現有標準（主規格 5.8）。

### 4.3 `/me` 套用（第 2 段）

- `me/index.html` 的 `:root` 設定搬到 `jte-theme.css`，頁面改引用 `../jte-theme.css` 與 `../jte-theme.js`。簡潔版的畫面必須與現在逐像素相同（只是設定換了位置）。
- 頁面裡寫死的顏色（不經過變數的）逐一改成變數，手帳版才換得到。
- 切換鈕放在右上角「首頁／我的練息場」旁邊，顯示「簡潔｜手帳」，目前的那個是選取態。手機上放在同一列，不擠到導覽。
- 頁面上的誠實印章、頁尾誠實句、求助專線在兩種風格下都維持可見、可讀。
- 示範模式（`?demo`）可以切換風格；風格偏好不屬於示範資料，會記住。

### 4.4 手寫字

現在整理區的手寫字用裝置內建字體：Mac 是翩翩體；Windows 與 Android 會退回標楷體或一般字，不像手帳。整頁標題都用手寫字後，這個差別會很明顯。

做法：內嵌一套手寫字體，只用在標題與少量點綴，內文不用。字體檔放進 repo，不從外部載入 script；字體本身可以用 `font-display: swap`，載入前先顯示一般字。

**待使用者決定**：用哪一套字體。實作前先找幾套可免費商用的繁體手寫字體，確認授權條款與檔案大小後列給使用者選。選定之前，手帳版標題先沿用現在的內建字體設定。

## 5. 不做的事

- 深色模式、每一頁各選各的風格。（2026-11-18 更新：使用者要求加第三種風格「手繪」，已加入：`doodle`，蠟筆（同日使用者指定「用蠟筆不要用麥克筆」，參考他的速寫本照片）：奶油色的紙、赭褐色的細線、塗色看得到筆觸與紙的顆粒、沒有陰影、標題底下掃一道多色蠟筆。原本這一條寫的「不做第三種風格」作廢。）
- 風格偏好跟著帳號同步到雲端。
- 依時段或狀態自動換風格。
- 八態能格的頁面。
- 第 3、4 段（首頁與工具頁）的內容：這一份只把共用基礎做到它們之後能直接引用。

## 6. 驗證

- 新的測試頁 `jte-theme.test.html`（用 `jte-testrun.py` 跑）：預設是簡潔；`set('sketch')` 後 `get()` 是手帳，`<html>` 的 `data-theme` 跟著變；重新載入後記得；不認得的值退回簡潔；localStorage 丟例外時不壞。
- `me/me.test.html` 維持全過。
- 手動：`/me/?demo` 兩種風格各截圖，五個空間都看過；手機寬度也看；切換時不閃；另一個分頁同步。
