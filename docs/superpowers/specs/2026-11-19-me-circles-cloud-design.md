# 一起練正式版（雲端）

日期：2026-11-19　狀態：已實作在本機，待部署規則後用真帳號驗證

## 起點

「陪伴」的一起練原本只有示範模式能操作（規格 2026-11-17 第 5.10 節）。使用者要它真的活絡起來，同意正式版。

沿用 11-17 已定的：可以瀏覽正在進行的團、加入、自己揪；開放加入或邀請制，一團最多 12 人；打卡附一句、四個鼓勵詞；沒有排名、不算連續天數、只列今天練了的人；可以這週先休息、隨時離開；團裡用自己取的名字；還沒加入的人只看得到彙總。

## 這次使用者決定的（2026-11-19，四題都照建議）

1. 任何登入（信箱已驗證）的人都能揪團。
2. 揪團的人可以請團員離開、可以結束這個團；平台管理者從 Firebase 主控台可以刪任何團。這一版不做檢舉。
3. 離開團時，自己在團裡打過的卡和寫的話一起刪掉。打卡時寫的那一句另外存在自己手帳裡的那一份不受影響。
4. 打卡這一版不和「我的練習」連動。

## 資料（Firebase 專案 lianxichang-me）

- `circles/{cid}`：`name`（1–16 字）、`tool`（工具代號或空白）、`what`、`rhythm`、`span`（0／7／21）、`start`、`open`、`owner`（揪團的人 uid）、`members`（uid 清單，1–12）、`lastIn`（每個團員最後打卡的日期）、`ended`、`createdAt`。
- `circles/{cid}/members/{uid}`：`nick`（1–12 字）、`resting`、`joinedAt`。
- `circles/{cid}/checkins/{日期_uid}`：`uid`、`k`（日期）、`text`（≤80 字）、`cheers`（團員 uid → 四個鼓勵詞之一）、`at`。一天一次靠文件代號保證。

## 誰看得到什麼（由規則保證，不靠畫面）

- 團本身：任何登入的人知道代號就讀得到（邀請連結靠這個，代號是 20 字隨機字串）；列出清單只能列開放加入的、或自己在裡面的。還沒加入的人看到的「今天幾個人練了」是從 `lastIn` 數出來的，看不到名字和心得。
- 團員名單與打卡：只有團員讀得到。
- 寫入：加入只能把自己加進去；打卡只能動自己那一格；離開只能拿掉自己；揪團的人只能減少團員、結束團，不能加人；鼓勵詞只能動自己那一格，不能替自己的打卡按。
- 平台管理者（`admins/{uid}`）讀得到全部、可以刪團。頁面上寫明這一點。

## 畫面

- 沒登入：說明要登入，附登入按鈕和「先看示範」。信箱沒驗證：請先驗證。
- 揪團、加入、邀請連結加入時，都要填「我在團裡的名字」，預設帶上次用過的名字（只存在這台裝置）。
- 每個團下面：這週先休息、複製邀請連結、團員 N 人（展開名單；揪團的人可以請人離開）、離開或結束（都要再確認一次）。
- 邀請連結是 `/me/?circle={cid}#care`。打開時沒登入會先請他登入；登入後在最上面問要不要加入。
- 讀取是打開頁面、切到「陪伴」（超過一分鐘才重讀）、做完每個動作時，不是即時推播。

## 沒做的

檢舉、團內留言串、和「我的練習」連動打卡、即時更新、揪團的人轉交、改團名。

## 一起改的

活動同步多讀「參加日期」欄：多場的分頁可以用「場次日期」或「參加日期」標明每一列是哪一場。
