## 1. 背景與目標

v3.1「敘事先行」示意(峰名卡 → 總述 → 四幕 → 伴讀 → 折疊詳細資料)給 Simon 過目後,收到五點回饋。本輪把 `octenso/bagua-report-v31-demo.html` 改成 v3.2 示意,仍用假資料,看過滿意後才動正式頁 `bagua-persona.html`。

## 2. 命名規則(全頁統一)

**者名在前、括弧放卦名**:「開創者(乾)」「明現者(離)」。

- 原三段式「開創者 · 乾 · 展行」退場;態雅稱(展行/照見/承載…)退到深讀區才出現。
- 敘事內文第一次點名也用同格式:「我們叫它開創者(乾)」。
- 雷達八角標籤用者名(加數字,見 §3.2)。

## 3. 頁面結構(v3.2 順序)

峰名卡 → 雷達圖 → persona 敘事 → 四個系統 → AI 伴讀 → 深讀折疊 → 留存分享 → 誠實聲明

### 3.1 峰名卡

標題改「開創者(乾)」;刪原「乾 · 展行」副標行。卦符、四行詩、「快照非標籤」聲明照舊。

### 3.2 雷達圖(升上主線,緊接峰名卡)

- 八角標籤:者名+數字直接顯示(如「明現者 74」)。
- 互動:點任一角,圖下方出現該態解釋卡——「明現者(離) 74 · 偏像你」+ 白話一句 + 作答篤定度(「兩可」時加註「解讀時請保留彈性」)。
- 預設選最高分的態。

### 3.3 persona 敘事(雷達圖下方)

v3.1 的「總述+四幕」併成一段連續 persona 描述:

- 先總述:一段零術語白話 + punch 句(地形判別選開場策略的機制照 v3.1)。
- 再接四幕內容(最突出的/如果這是你/四個系統的呼應),寫法仍「人話先行、命名跟上」。
- 原幕二(可信度)的逐態篤定度已被雷達解釋卡吸收;敘事裡只留一段整體可信度的話。

### 3.4 四個系統(更詳細、更白話)

每系統從一行結論擴成一小段:

1. 音量條一對(者名(卦)+數字)
2. 一行結論(偏向/雙高張力/均衡)
3. 三、四句白話:這一對力氣在拉什麼、你現在的形狀是什麼、日常會長什麼樣子、一個具體的小練習。

C1 規則照舊:僅四對待可講關係,僅雷風(震巽)=張力。

### 3.5 深讀折疊區(瘦身)

雷達與四系統升上主線後,折疊區剩:「剛剛好嗎」(亢/潛/中正)與「你的章節」。態雅稱在此層才出現。

### 3.6 其餘照 v3.1

AI 伴讀(引用 punch 句開場)、留存分享、誠實聲明(v0.1 研究假設·待考、localStorage 不上傳、假資料標註)不動。
