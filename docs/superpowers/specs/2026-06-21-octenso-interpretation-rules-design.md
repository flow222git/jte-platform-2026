# 八態能格 · 解讀引擎規則（Interpretation Rules）設計 spec

整理日期：2026-06-21
定位：這是**解讀層的憲法**，與《八態能格學理憲法》（`2026-06-19-octenso-bagua-model-calibration-design.md`，管「模型對不對得上八卦學理」）並列。本 spec 管的是下一層——**「怎麼把一份分數，說成貼著本人、又不失真的話」**。

> 模型憲法答「離到底是什麼」；本 spec 答「測出來之後，那段解讀怎麼寫才合理、不貼標籤、不誤解人」。

---

## 0. 為什麼要這份 spec（風險與立場）

我們動的是**「人怎麼看自己」**。解讀寫歪，不是一個 bug——它會讓一個人**誤解自己是誰**。三種具體危險：
1. **不準**：說的不是這個人 → 失去信任。
2. **貼標籤**：把人收進固定盒子 → 違反「八態給鏡子＋調音台、非盒子」。
3. **似是而非的因果**：把獨立的能量硬扯成因果（如「因為你喊停低，所以行動失控」），聽起來合理、其實沒根據 → 最危險，因為它**像真的**。

**北極星**：
- 解讀是在「**把潛意識的能量習慣，搬到意識來看**」（使用者老師語）。
- **鏡子，不是算命**：只描述「你感受到的傾向／此刻」，不預測行為、不斷吉凶。
- **felt-self**：報告照的是「你**感受到**的自己」，不是行為審計；它跟「別人眼中的你／你的足跡」之間的落差，是**反思題，不是誤差**。

## 1. 唯一可用的「素材」（其餘一律不准捏）

解讀只能由以下**模型認可的元素**推出。任何一句話都必須能指回其中之一（見硬約束 C7）。

| 素材 | 是什麼 | 性質 |
|---|---|---|
| **相對高低（ipsative dev）** | 每股減掉此人平均後的偏離 → 形狀、主峰、低谷 | 單股 |
| **四對待** | 唯一被認可的「兩股之間」關係：開創↔承接、行動↔拓展、沉澱↔明現、喊停↔交流 | 兩股（限定配對） |
| **能格（潛／中／亢）** | 單一股「用太少／剛好／太過」的代價 | **單股**（非跨股比較） |
| **缺口** | 相對最低的股 | 單股 |
| **整體水平** | 八股平均高低（給能格、場景用） | 全域 |

**四對待的德**（出《說卦傳》先天對待，已校準）：
- 天地定位（開創↔承接）＝建構，**和諧·完整格局**
- 雷風相薄（行動↔拓展）＝推動，**唯一的「張力」**（鼓盪）
- 水火不相射（沉澱↔明現）＝認知，**和諧·既深又亮、相成**
- 山澤通氣（喊停↔交流）＝調節，**和諧·進退有節**

## 2. 硬約束（HARD CONSTRAINTS，永遠不可違反）

- **C1 能量獨立**：不得在兩股**獨立**能量之間捏造因果或互動——**除非**那兩股正好是四對待的一對（見 C3）。
  - ✗ 反例（曾犯）：「行動旺、喊停只有 38 → 你卡住時最坐不住」。喊停（艮）與行動（震）不同對、模型無此關係。**禁止。**
- **C2 一拍一層**：每段解讀只用**一個能格層次**——中正（強項）／過用（代價）／不足（空間）——三者不可在同一段互相污染。
- **C3 組合僅限四對待**：跨能量的「關係／互動」描述，**只在**那兩股恰為四對待一對時才可講，且依該對的德（只有雷風＝張力，其餘＝和諧）。非配對的兩股，只能並列為「兩個獨立強項」，不得宣稱機制。
- **C4 中正 ≠ 亢**：講「優勢／發揮」只用**中正（用得好）**的樣子；**衝動／焦躁／停不下來＝過用（亢）**，一律歸能格層（拍 2），不得寫進優勢。
  - ✗ 反例（曾犯）：把行動的優勢寫成「想做就動的衝勁」——那是亢（衝動），不是中正強項。中正＝執行力、推動落地、卡關能突破。
- **C5 描述非預測**：只說傾向／此刻，不預測「你會做出 X」、不斷吉凶禍福。
- **C6 felt-self 揭示**：解讀須（在框架處）言明這是「你感受到的自己」、會流動、非行為審計；落差是反思題。
- **C7 可追溯**：每一句解讀都要能指回 §1 的某個素材。指不回的＝似是而非，刪。
- **C8 價值中性**：任何能量不被框成「好／壞」；高、低、過、不足都是「樣態」與「線索」，不是評價。

## 3. 三拍圖文解讀結構（結果頁的「解讀描述」）

整體畫面＝此人的**能量圓**（由真分數長出的有機形狀）。其下以三拍把圓讀出來，每拍＝一個迷你圓（點亮對應處）＋一句話。**三拍各守一個能格層次（C2）**：

### 拍 1 · 你的優勢（主組合）— 只用「中正強項」
- **取**：相對最高的 1–2 股（ipsative leads）。
- **說**：這是你最鮮明／拿手的能量＝你的本錢。
- **給**：「怎麼更發揮」＝**每股自己「用得好（中正）」的方向**（見 §5 能量中正詞庫）。
- **組合**：若 top-2 恰為四對待一對 → 依該對的德講（如沉澱↔明現雙高＝「既深又亮」）；**否則並列為兩個獨立強項**，可說「都是本錢、可以搭起來用」（機會語氣），**不得宣稱「A 因為 B」**（C1/C3）。
- **寫法（能量速寫·畫面感）**：本拍是「速寫」——畫「眼前有什麼」，不解釋「為什麼」。把兩股強項的**並存畫面**寫得有畫面感即可（兩股都高是事實）。
  - ✓ 並存：「在你身上，又有一股想往前衝的勁、又有一份沉得住的定。」「你既能…也能…」
  - ✗ 因果：「因為你想透了，所以才動。」「你既…所以…」← 捏機制，違反 C1。
  - 口訣：**並存可以，因果不行。**

### 拍 2 · 用得剛不剛好（能格）— 只用「過用代價」或四對待
- 主導股若**過用（亢）** → 講**它自己**過頭的代價（行動過用＝焦躁、難收手）。明示是這股**自己**的事，非他股所致（C1）。
- 若四對待**雙高** → 用該對讀法（多為和諧；**只有雷風＝張力**）。
- 若都**中正**（無極端 → 未觸發能格校準、無資料）→ **不硬找張力**；改問 **1 題「中性確認」**：這份平均是「**真的平衡、有彈性**」（優點）還是「**還在摸索、還沒長開**」（空間）？依答覆給對應讀法（彈性／待開發），不亂貼。
- 註：能格需「校準題」資料。極端態 → 問代價校準題；全中性 → 問上述中性確認題；兩者都讓拍2 有據可說。

### 拍 3 · 還沒長開（缺口）— 只用「不足空間」
- **取**：相對最低的股。
- **說**：這股你較少動用、最有空間；**它本身**能帶來什麼（該股的正向價值）＝可以長的方向。
- **禁**：不連到別股（不說「因為缺它，所以你 X」）（C1）。只點出 ＋ 它自己的價值，就到這。

## 4. felt-self 框架（讀任何細節之前先戴的眼鏡）

結果頁在能量圓之後、三拍之前，放一段框架（已上線於 `bagua-persona` showResult）：
> 這是把你平常沒留意的能量習慣搬到眼前——它照的是**你「感受到」的自己**，不是行為審計。別人眼中的你可能不一樣；那個落差不是錯，最值得停下來想：哪些是你的**底色**，哪些是某個場景把你**暫時長出來**的樣子？

## 5. 能量「中正詞庫」（拍 1 用，描述用得好的樣子；草稿待潤）

只列中正（強項）面；亢／潛的措辭分別在能格層。

| 能量 | 中正強項（拍1 可用） | 過用·亢（拍2） | 不足·潛（拍3 正向價值＝它能帶來的） |
|---|---|---|---|
| 乾·開創 | 立方向、開局、作主 | 控制欲、獨斷、脫離現實 | 方向感、願景 |
| 坤·承接 | 承載、滋養、讓事穩穩運轉 | 過度承擔、失去自我 | 耐心、穩定、接得住 |
| 震·行動 | 執行力、推動落地、卡關能突破 | 衝動、焦躁、停不下來 | 啟動、不拖延 |
| 巽·拓展 | 連結資源、順勢鋪開、彈性 | 攤太開、失焦、難拒絕 | 觸及、把人事物連起來 |
| 坎·沉澱 | 沉得住、想得深、能恢復充電 | 內耗、逃避、退縮 | 沉著、定力、判斷的底 |
| 離·明現 | 看清＋把它顯現／讓人看見 | 過度分析、太想被看見 | 洞察、表達、被理解 |
| 艮·喊停 | 守界線、定位、知所進退 | 固執、停滯、不變通 | 設界線、喊卡、守節奏 |
| 兌·交流 | 表達、互通、把話說開 | 過度社交、討好、空談 | 連結人、把感受說出口 |

（此表須回溯對得上《學理憲法》的卦德／五行／爻位欄。）

## 6. 語氣（voice）

- 第二人稱、**平實關懷的鏡子**；不奉承、不戲劇、不下指導棋。
- 價值中性（C8）：高低過不足都是「樣態／線索」。
- 具體生活實感優先於抽象命名（但不得為了生動而捏因果——C1 凌駕一切）。

---

## 7. 治理（governance）

- **每一句解讀（現有＋未來）都必須能對到本 spec 的某條規則**；對不上＝bug，改。
- 本 spec 管「解讀層」，《學理憲法》管「模型層」。兩者衝突時，先確認模型，再寫解讀。
- 涉及人性，**寧可少說、不可亂說**：拿不準是否捏因果時，退回「只描述單股」。

## 8. 完整範例（樣本：行動82・沉澱78・喊停38）

**✓ 合規版**
- 拍1 優勢：你最鮮明的是**行動與沉澱**。行動——你能把想法**啟動、推著落地**，卡關時用行動突破，這是你的執行力；沉澱——你**沉得住、想得深**，獨處能恢復，這是你判斷的底。兩股都是本錢，能搭起來用。
  - 註：行動與沉澱非四對待一對 → **只並列、不宣稱「想透才動」這種機制**（那是 C1/C3 違規，雖好聽）。
- 拍2 能格：（需校準資料。若行動偏過用 → 可能焦躁、難收手——這是行動**自己**的事。都中正則：你這幾股用得挺剛好。）
- 拍3 缺口：**喊停**你最少用——它能幫你設界線、喊卡、守住節奏；刻意練一點，會讓你更保護得住自己的能量。（到此，不連回行動）

**✗ 違規版（曾犯，當反面教材）**
- 「行動旺、喊停只有 38 → 卡住時最坐不住、引擎空轉」← **違反 C1**（喊停與行動無關係，捏因果）。
- 「把握想做就動的衝勁」當優勢 ← **違反 C4**（衝勁＝亢，不是中正強項）。
