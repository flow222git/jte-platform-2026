# 八態能格 · 向量函式層 設計 spec(八態向量+四門座標的數學層)

整理日期:2026-07-13 ｜ 狀態:**定義定案、參考值 v0.1 待試測校正**——純數學層,不動測驗與報告
緣起:使用者提問「把測出來的百分比變成數學函式,得出立體完整的你?」+「四個門一起加入」。
定調:**「立體完整的你」=八維向量本身**(晶體渲染的就是它);函式層不做加權融合(壓扁+把排名雜訊當訊號),只做三件事:**變化、相似、比對**。

## 0. 基本物件

- **八態向量** v = (乾, 離, 震, 兌, 坤, 坎, 艮, 巽) ∈ [0,100]⁸ ——完整的你,一分不丟。
- **四門座標**(由 v 換底,免費取得;g 的兩極為 l, r):
  - 傾向 tilt_g = s_l − s_r ∈ [−100, 100](正=偏左極;絕對值=偏多少)
  - 開度 open_g = (s_l + s_r) / 2 ∈ [0, 100](這道門整體開多大)
- 八態 ⇄ 四門×(傾向, 開度) 是**可逆線性變換**:同一份資訊、兩種讀法。門座標的價值=可讀性(對人說話用門,對機器算距離用態)。

## 1. 函式一:重測差異 Δ(月照鏡的引擎)——優先做

- 逐態差 δ_k = v₂ₖ − v₁ₖ;整體移動量 D = √( Σ δ_k² / 8 )(RMS,0–100 同尺)。
- 門座標差:Δtilt_g、Δopen_g ——敘事主角。
- **雜訊地板 NOISE = 8**(v0.1 假設;重測信度資料進來後校正):|δ| < NOISE 一律說「大致穩定」,不敘事——把測量誤差當變化講,是另一種算命。
- 敘事模板(草案):
  - 整體:D < 6 「這個月你的形狀很穩」/ 6–14 「有些流動」/ >14 「明顯的移動」
  - 逐門:「{門}之門:傾向從 {t₁} 移到 {t₂}(往「{極}」靠了 {Δ});開度{升/降/持平}。」
  - 憲法檢核:只描述位移,不解釋原因、不評好壞(「坎長了」≠「你進步了」)。
- 落地:bagua-records 已存歷史紀錄——在紀錄頁加「這兩次之間」對照卡;或伴讀版重測時開場直接說。

## 2. 函式二:形狀相似(合盤/團隊)

- 兩人比形狀,先各自去水平(ipsative):v̂ = v − mean(v);相似度 = cos(v̂₁, v̂₂) ∈ [−1, 1]。
- 水平差(整體高低)另外報,不混進形狀——「形狀像不像」與「電量高低」是兩件事。
- 門座標版:逐門比 tilt——「你們在開闔之門一個偏關門、一個偏找人聊」——合盤的一句話素材。
- 憲法:僅對照、不配對建議、不速配分數(那是算命的皮)。

## 3. 函式三:原型比對(roadmap,暫緩)

- 若日後建 64 重卦人格庫(主卦上、次卦下),正確做法=**向量比對最近原型**(距離最小的典型形狀),不是加權混合文案。
- 前置:64 篇內容+理論檢核+試測頻率(先看哪些組合真實存在)。列 roadmap,不排期。

## 4. 明確不做(否決紀錄)

- **加權求和成單一分數**:把八維壓一維,兩個不同的人會同分——「立體」死於求和。
- **按排名連續配權**:分數相近時排名劇烈翻轉(82:81),同人重測輸出大變,違反可重現;分佈中段的排序本是雜訊。
- **文案加權混合**(40% 乾文+25% 離文):句子不是向量;且=引擎自動跨股融合,違反 C1。
