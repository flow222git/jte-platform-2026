## 1. 架構：零新增卦表，全靠反查

- **剛＝陽、柔＝陰**。三爻（理/用/道）剛柔判定組合，反查 `OCTENSO_DAOLIYONG.MODES[].yao` → 本卦（卦名、副題、trait、blindspot、guard 全部現成）。
- **一爻變**＝翻轉該爻陰陽再反查 → 之卦與其腳本現成。
- 唯一新增程式：`daoliyong-data.js` v1.1 加兩個 helper——
  - `guaOf(li, yong, dao)`：各值 `'yang'|'yin'`，回傳相符的 MODES 條目（8 組合必中其一）。

## 2. 剛柔判準（已逐條核准，2026-07-21）

每爻判**剛/柔**（性質，無優劣）＋**安/動**（亢＝剛過極、溺＝柔過極，即動爻）。判定自帶 G5：每格附逐字引文，引不出＝該爻不判＝不成卦。剛柔證據池與⑤ presence 獨立——⑤問「這層有沒有料」，判卦問「這層怎麼運作」，同句引文可餵兩邊、判不同問題。

### 理爻（地）——根基怎麼立

| 判定 | 樣態 | 識別信號 |
|---|---|---|
| 剛 | 立場鮮明、根基自信 | 明確原則與標準宣告；方法論有主張（「我們的做法是」）；依據直陳不繞 |
| 柔 | 虛心開放、根基謙遜 | 承認知識邊界；假設保持開放；多引他山之石；「還在學／還在驗證」姿態 |
| 亢（剛過極，動） | 教條僵化 | 依據不容質疑；唯我獨真；標準僵死不隨境調——理箴「勿死守僵化教條」的現場版 |
| 溺（柔過極，動） | 根基失守 | 無主見、立場隨人搖擺；什麼都「再看看」；根基借來的沒還（如：新場域仍全靠舊場域的據） |

### 用爻（人）——怎麼出手

| 判定 | 樣態 | 識別信號 |
|---|---|---|
| 剛 | 強推直取 | 直接執行、高速輸出；正面對決；大開大闔的行動風格 |
| 柔 | 柔性手腕 | 繞道鋪陳、借力使力；彈性調整；以退為進 |
| 亢（動） | 出手過極 | 輸出停不下（「高輸出、低復原」）；硬碰硬四處樹敵；過勞執行——用箴「不可盲目功利」的現場版 |
| 溺（動） | 出手失守 | 鋪陳無限、始終不進正題；應變到失去主軸；行動被環境完全牽走 |

### 道爻（天）——格局的姿態

| 判定 | 樣態 | 識別信號 |
|---|---|---|
| 剛 | 進取格局 | 擴張的願景；成就導向的頂層追求；把天花板往上頂 |
| 柔 | 開闊留白 | 不做絕、留退路與餘裕；和諧共生視角；長期自然節奏 |
| 亢（動） | 格局繃死 | 零餘地、唯效率、竭澤而漁；「假期也不敢休」；撐到裂 |
| 溺（動） | 格局空掉 | 玄談不落地、願景無錨；躺平無為失去生機——道箴「勿流於玄妙空談」的現場版 |

**學理註腳**：三隅箴各是某爻過極的警語——理箴＝理亢、用箴＝用亢、道箴＝道溺。亢/溺表把每爻兩側的過極補齊，與三隅箴並存不衝突。

## 3. 變爻判定律（三源合流，使用者定案）

1. **脈絡優先（第一順位）**：判剛柔時同判安/動——呈「亢」或「溺」之爻即動爻，附「何以見動」引文。動爻＝變爻，從脈絡判之。方向不預設（變可起於初爻、爆於上爻、卡在中爻），素材說了算。
2. **宣告校正（第二順位）**：有目標＋TA 宣告時——動爻與目標同向，直接定；多個動爻或動爻與目標指向不同，以宣告裁決，並列註明「脈絡動爻在 X，目標指向 Y」（分歧不隱藏）。
3. **菜單兜底（第三順位）**：無動爻、無宣告 → 列三條一爻變路徑，各附一句適用時機，選擇權還給使用者（G8 不猜）。
4. **一律一爻變**：多爻變不做——一次給一個功課，才是可執行的處方。

## 4. 輸出格式：⑥段改版「判卦與轉化參考」

宣告體系四項：素材類型（必）、判讀對象（必）、**目標（可選）、TA（可選）**——「宣告越齊、⑥越準」。

```
①–④ 八態(不動)
⑤   三角形體檢(不動:presence+三隅箴)
⑥   判卦與轉化參考(改版,工作假說標記):
     ├─ 剛柔判定表:三爻各判 剛/柔＋安/動,每格附逐字引文(G5)
     ├─ 本卦:卦名+副題+此局死角(MODES 反查,機械推導)
     ├─ 變爻:三源合流(§3),附「何以見動」引文或宣告依據
     └─ 之卦:轉化參考腳本+「新死角」(之卦自身 blindspot——換一種活法就換一種死法)
     不成卦:明文聲明+缺哪爻+補問;⑥退回 v2 行為(bestUse 對照引用)
G7 型(interview/observation):⑤⑥一律不出(不變)
```

TA 註記沿用 v2 backlog 定案：TA＝素材的受眾，非判讀對象，不對 TA 做人的評價（G4）。

### 4.5 三角形量形圖（⑤的視覺化，使用者 2026-07-21 定案）

- **頂點長度＝⑤ presence 三段**：有料＝長、薄＝中、缺席＝短——離散判定等級，非分數（§8 紅線不變，不做 1–10 邊長）。
- **形態命名與對應語彙**（引 canonical 警示語彙，不另造）：完整三角（三層有料）＝完整格局；道頂縮＝**趨韓非形**（引唯用無道／道箴語彙，原典「不完整三角形」的視覺化）；理頂縮＝空談形；用頂縮＝自產病形；多頂縮＝依缺席清單並列敘述。
- **輸出**：⑤段附一句「量形描述」（例：「理長用長道中——趨韓非形之初」）；判讀報告網頁版依三段長度繪三角形，縮頂以虛線表示（比照 `Integral_Philosophy_Triangle.pdf` 第 9 頁不完整三角形畫法）。
- **邊的關係判讀不在本輪**：三條邊的古典本義（理→用＝以用為歸宿之貫通、用→道＝反於道之節制、道→理＝境界回灌根基）屬全新判讀學，需識別信號逐條核准——另立 spec，已記 backlog。

## 5. 誠實條文（判卦四律）

1. **非占卜律**：爻由判讀而來（每爻附引文）、變由診斷與宣告而來——無一絲隨機。報告必附 canonical 聲明（入 schema，各頁不得自寫）：「此卦由素材判讀推導，非起卦占斷；變爻是處方，不是預言。」
2. **機械推導律**：AI 只做剛柔與安動判定，卦由 `MODES[].yao` 反查自動得出——不得跳過判定直接「感覺是某卦」。同素材同判定必同卦，可追溯。
3. **主詞律（G4）**：卦名給運作不給人——「此局呈乾象」可以，「你是乾卦」不行。
4. **不預測律（G1）**：之卦是參考路徑，不是「將會變成」；本卦死角是結構警訊，不是命運。判卦整段掛「工作假說·待收斂」，收斂前不進正式產品文案。

## 8. 本輪不做（YAGNI）

- 多爻變、六爻重卦（64 卦）——一爻變是唯一的處方形式。
- 剛柔不做程度分（只判剛/柔/亢/溺四態，不給 1–10 分——量化假精確是算命的近親）。
- persona 測驗端（永遠不動）、UI 頁（另輪）、i18n、WH1 時間軸（不與判卦混流）。
