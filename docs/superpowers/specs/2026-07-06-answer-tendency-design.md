# 答題傾向 2×2（標註式）· 設計

- 日期：2026-07-06
- 對象檔案：`octenso/bagua-persona.html`（八態能量人格測驗）
- 類型：結果頁新增功能（標註式，不改動現有解盤邏輯）

## 目標

施測完成後，在結果頁**最上方**先呈現一張「答題傾向 2×2」卡，標出使用者落點與一段解讀，讓人「先看自己怎麼作答，再看解盤」。用兩個可直接從答案算出的軸，交叉出四個核心類型。

## 兩軸（複用現有引擎，不加題）

量表 0–5、中點 2.5（`SMAX=5`）。兩軸皆正規化 0–1。

- **橫軸 · 極端度 E** ＝ 全部有效作答 `|v − 2.5| / 2.5` 的平均。
  - 直覺：0＝全選中間、1＝全選兩端。隨機作答理論中點約 0.6。
  - **門檻：E ≥ 0.6 → 偏極端；否則偏中間。**
- **縱軸 · 一致性 C** ＝ 複用 `computeConf()` 的輸出，取**非 `mixed`（firm＋mild）態的佔比**。
  - 直覺：你有幾成向度內部互相呼應。對齊現有 `mixed`（同態 spread≥3＝兩可）判定。
  - **門檻：C ≥ 0.6 → 一致；否則不一致。**

門檻 0.6/0.6 為上線初值，之後可微調。

## 四型

| | 一致（C≥.6） | 不一致（C<.6） |
|---|---|---|
| 極端（E≥.6） | 鮮明型 · 極端且穩定 · 自我認識清晰 | 擺盪型 · 極端但矛盾 · 強烈卻互相衝突 |
| 中間（E<.6） | 均衡型 · 中間但穩定 · 真心覺得中等 | 游移型 · 中間且飄忽 · 看情況、還在找 |

各型一句定性 ＋ 一段解讀：
- 鮮明型：答案往兩端且互相呼應，可信度高。
- 均衡型：誠實地偏中／流動，宜看「分布均衡」而非硬擠主型。
- 擺盪型：回答用力但矛盾，反映內在張力或情境差異。
- 游移型：可能仍在自我探索或動機不足，信心水準宜調低。

（標註式階段只呈現文字，不改型態判定、不改信心語氣、不做導流。）

## 視覺

- 仿 2×2 象限圖：四象限方塊 ＋ 軸標（上「一致性高」、下「一致性低」、左「偏中間作答」、右「偏極端作答」）＋ 依 (E, C) 定位的落點圓點；亮起使用者所在象限。
- 配色沿用本檔 tokens：`--pine`（鮮明）、`--muted`（均衡）、`--blue`（游移）、`--cinnabar`（擺盪）、`--line`/`--surface`。

## 資料流與邊界

- **新測**：`computeTendency(conf)` 用全域 `answers` 算 E、用 `conf` 算 C，回傳 `{E,C,type}`。並把此物件一起存進 `bagua_persona_v1`（`showResult` 存檔處）。
- **看記錄（`viewScores`）**：讀存檔的傾向；舊記錄無此欄位 → 優雅略過該卡（不報錯）。
- **分享檢視（看別人報告）**：無 `answers`、走另一段渲染 → 天然不顯示。

## 放置點

`showResult` 組字串處，`fsbar` 之後、`typecard` 之前插入 `tendencyCard(tend)`（tend 為 null 時插空字串）。

## 實作範圍

1. `<style>` 新增傾向卡 CSS。
2. JS 新增：`computeTendency()`、型別定義表（label／定性／解讀／色）、`tendencyCard()` HTML builder。
3. `showResult`：計算或讀取 tend、存檔時一併寫入、字串注入。
