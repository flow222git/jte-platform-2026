## 0. 一句話(補上缺的動詞)

現有:「看見你的能量,選擇你的流動。」缺第三個動詞:**練**。

> **鏡(看見)→ 橋(翻譯)→ 場(練)→ 再照鏡。**
> 鏡=八態能格/HRV/心情溫度/問易;橋=Route B 與「三個方向」;場=呼吸覺察/小憩練息/書寫;AI 伴讀陪你走完整條迴圈。

**護城河**:九型有鏡子沒練功房;冥想 App 有練功房沒鏡子;練息場兩者兼備,中間還有 HRV 當客觀裁判——「練完,身體真的變了」。主觀鏡子+生理證據+練習閉環,同時做到三件事的沒有第二家。品牌底氣即「科學,讓療癒更有據」。

## 2. IA:從「工具目錄」到「一人一頁」

經營心智圖已給答案:「從 modality 目錄 → 被愛的社群之家」。UX 的基本單位改為**「我的練息場」個人頁**:

```
┌─ 我的練息場 ──────────────────────────┐
│ 我的底色   八態峰名卡+迷你雷達(季)      │
│ 此刻       三態快篩(空/滿/卡)+心情溫度   │
│ 今日一步   三個方向 → 直連對應練習       │
│ 身體的話   HRV 趨勢、練習前後對比        │
│ 我的處境   最近的卦+Route B 建議        │
│ 伴讀       帶完整快照去跟 AI 聊(管家包)  │
└──────────────────────────────────┘
```

**技術要點**:所有工具的資料已在 localStorage——個人頁=純前端聚合,零後端即可成立。這是整合成本最低、體感最強的第一步。各工具維持獨立頁(deep link),個人頁是家、不是牢籠。

## 3. 旅程:每個工具在對的時刻出現

1. **第一分鐘(前門)**:三態快篩。空了→HRV+恢復呼吸;太滿→喊停工具+卸壓呼吸;卡住→八態深鏡。(策略頁原設計,搬到真首頁。)
2. **深鏡之後(掛鉤)**:報告「三個方向」逐條接練習——乾亢→承接式呼吸、坎潛→十分鐘小憩。需補一份**練習↔八態反向標籤**(每個呼吸法補哪股/收哪股;E.tools 的逆向)。
3. **練習前後(證據=aha moment)**:HRV 三明治——練前量、練後量,做成儀式。
4. **事件觸發(橋=皇冠時刻)**:遇到處境→問易→卦的召喚 × 你的能格=Route B 客製建議→回到練習。
5. **節奏(留存)**:HRV 日、心情週、八態季+對境耗能(愛情/工作深入)按需——三種週期=自然回訪理由;個人頁顯示「下一次照鏡」。

## 4. 共通語:八態是平台的 lingua franca

- 每個工具都說八態的語言:HRV 報告可註「恢復(坎)的身體版」;呼吸法標「補哪股/收哪股」;BSRS 偏高→坤/坎 照顧路徑;優勢幸福力的優勢清單→對映八態中正語言,餵「好好用」。
- 真相來源維持單一:`bagua-data.js` canonical(meta A 原則擴大到全平台)。
- 視覺已統一(DESIGN-PRINCIPLES/house-style),不需另做。

## 5. AI:兩層,分開決策

- **讓使用者更了解自己(全力做)**:伴讀包 → **管家包**——複製的從單份報告升級為整份「我的練息場」快照(八態+近期 HRV+心情+練習紀錄),AI 從「陪讀一份報告」變成「認識整個你」。仍零後端、隱私自主。內嵌對話列第二階段(serverless+金鑰,俟價值驗證)。
- **讓平台更了解使用者(戰略決定,不是功能)**:撞「作答不上傳」北極星。先走策略頁既有的**回饋迴路**:「這個解讀貼切嗎?」一鍵匿名回傳(opt-in、單點)——給模型修正最需要的資料,不動搖隱私承諾。全面帳號化與資料回流,綁 Route C(真人/社群層)一起決策。

## 6. 優勢幸福力與研究層(槽位保留)

- 優勢幸福力=「資源盤點」,與八態「能量盤點」互補;其優勢項→八態中正對映表(如 VIA↔八態),產出餵個人頁「好好用」。
- 心理學研究頁=誠實印章彈藥庫(比照 hrv-research 成頁,標註證據等級)。
- 併入方式:該專案 repo 加入工作區後,依本藍圖 §4 掛上共通語。

## 7. 動工順序(每步獨立可上線)

| # | 項目 | 為什麼先它 |
|---|---|---|
| ① | **「我的練息場」個人頁**(localStorage 聚合) | 成本最低、體感最大;整合的「家」先立起來 |
| ② | 三個方向 → 練習接線(練習↔八態反向標籤) | 鏡到場的掛鉤;資料半現成 |
| ③ | 對境耗能·愛情+工作(已 GO) | 深鏡的縱深;T2 積木就位 |
| ④ | 問易 × 八態 Route B MVP | 皇冠時刻;64 卦表已 v0.1 |
| ⑤ | AI 管家包(快照版伴讀) | ①的自然延伸 |
| ⑥ | 回饋迴路(貼切嗎?匿名回傳) | 模型越用越準的引擎 |

## 8. 誠實邊界(平台級)

- 誠實印章是品牌資產:「v0.1 研究假設·待考」照掛。
- 鏡子非算命:個人頁任何跨工具的併陳=**並列呈現,不捏跨工具因果**(C1 的平台版——HRV 低+乾亢只能並列,不得宣稱機制)。
- 三種鏡子(自評/生理/情緒)不一致時,呈現為**反思點**,不裁決誰對。
