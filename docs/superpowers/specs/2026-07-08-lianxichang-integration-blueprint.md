# 練息場 · 平台整合藍圖(鏡 · 橋 · 場)

整理日期:2026-07-08 ｜ 性質:平台級整合策略+UX 藍圖(spec)
上游:`platform-intro/index.html`(雙層模型/四層堆疊/三態分流)、`platform-intro/strategy.html`(Route A/B/C/誠實印章)、2026 經營策略心智圖(「從 modality 目錄 → 被愛的社群之家」)、本輪八態能格全部成果(型錄/題本 v2/AI 伴讀/三個方向)
定位:**不另立新策略**——把白皮書既有的策略骨架,收斂成一個使用者感受得到的整體:一句話、一張個人頁、一條旅程、一個共通語、一條動工順序。

## 第一原則:整體感,不硬整合(使用者定案,凌駕本文其餘內容)

平台要的是**整體感**——同一個家、同一種語氣與誠實邊界、工具間的轉介動線;**不是硬整合**——不做系統間量表對映、不強制翻譯彼此語言、不為統一而稀釋任何一方的公信力。本文所有「整合」皆依此解讀。

## 0. 一句話(補上缺的動詞)

現有:「看見你的能量,選擇你的流動。」缺第三個動詞:**練**。

> **鏡(看見)→ 橋(翻譯)→ 場(練)→ 再照鏡。**
> 鏡=八態能格/HRV/心情溫度/問易;橋=Route B 與「三個方向」;場=呼吸覺察/小憩練息/書寫;AI 伴讀陪你走完整條迴圈。

**護城河**:九型有鏡子沒練功房;冥想 App 有練功房沒鏡子;練息場兩者兼備,中間還有 HRV 當客觀裁判——「練完,身體真的變了」。主觀鏡子+生理證據+練習閉環,同時做到三件事的沒有第二家。品牌底氣即「科學,讓療癒更有據」。

## 2. IA:從「工具目錄」到「一人一頁」

經營心智圖已給答案:「從 modality 目錄 → 被愛的社群之家」。UX 的基本單位改為**「我的練息場」個人頁**:

```
┌─ 我的練息場 ──────────────────────────┐
│ 我的底色   八態峰名卡+迷你雷達(季)      │
│ 此刻       三態快篩(空/滿/卡)+心情溫度   │
│ 今日一步   三個方向 → 直連對應練習       │
│ 身體的話   HRV 趨勢、練習前後對比        │
│ 我的處境   最近的卦+Route B 建議        │
│ 伴讀       帶完整快照去跟 AI 聊(管家包)  │
└──────────────────────────────────┘
```

**技術要點**:所有工具的資料已在 localStorage——個人頁=純前端聚合,零後端即可成立。這是整合成本最低、體感最強的第一步。各工具維持獨立頁(deep link),個人頁是家、不是牢籠。

## 3. 旅程:每個工具在對的時刻出現

1. **第一分鐘(前門)**:三態快篩。空了→HRV+恢復呼吸;太滿→喊停工具+卸壓呼吸;卡住→八態深鏡。(策略頁原設計,搬到真首頁。)
2. **深鏡之後(掛鉤)**:報告「三個方向」逐條接練習——乾亢→承接式呼吸、坎潛→十分鐘小憩。需補一份**練習↔八態反向標籤**(每個呼吸法補哪股/收哪股;E.tools 的逆向)。
3. **練習前後(證據=aha moment)**:HRV 三明治——練前量、練後量,做成儀式。
4. **事件觸發(橋=皇冠時刻)**:遇到處境→問易→卦的召喚 × 你的能格=Route B 客製建議→回到練習。
5. **節奏(留存)**:HRV 日、心情週、八態季+對境耗能(愛情/工作深入)按需——三種週期=自然回訪理由;個人頁顯示「下一次照鏡」。

## 4. 共通語:八態是平台的 lingua franca

- 每個工具都說八態的語言:HRV 報告可註「恢復(坎)的身體版」;呼吸法標「補哪股/收哪股」;BSRS 偏高→坤/坎 照顧路徑。共通語適用於練息場自有工具;優勢幸福力為獨立實證量表,**不納入對映**(見 §6.5 並列不融合)。
- 真相來源維持單一:`bagua-data.js` canonical(meta A 原則擴大到全平台)。
- 視覺已統一(DESIGN-PRINCIPLES/house-style),不需另做。

## 5. AI:兩層,分開決策

- **讓使用者更了解自己(全力做)**:伴讀包 → **管家包**——複製的從單份報告升級為整份「我的練息場」快照(八態+近期 HRV+心情+練習紀錄),AI 從「陪讀一份報告」變成「認識整個你」。仍零後端、隱私自主。內嵌對話列第二階段(serverless+金鑰,俟價值驗證)。
- **讓平台更了解使用者(戰略決定,不是功能)**:撞「作答不上傳」北極星。先走策略頁既有的**回饋迴路**:「這個解讀貼切嗎?」一鍵匿名回傳(opt-in、單點)——給模型修正最需要的資料,不動搖隱私承諾。全面帳號化與資料回流,綁 Route C(真人/社群層)一起決策。

## 6. 優勢幸福力與研究層

- 優勢幸福力=獨立的實證資源盤點,與八態**並列不融合**(定案見 §6.5);併入工作區後做的是並列呈現+轉介動線+企業儀表板,不做量表對映。
- 心理學研究頁=誠實印章彈藥庫(比照 hrv-research 成頁,標註證據等級)。

## 6.5 雙輪:To-B × To-C(2025 年度報告帶來的升級)

2025 A 集團年終報告(練息場 × 合作諮商所)揭示:**練息場已是進行中的 To-B 事業**,整合藍圖因此從單輪升級為雙輪。

### 既有 To-B 實績(不是規劃,是數據)
- 療癒工作坊(Sensory Chill):640 人/21 場,身心舒緩平均 +3。
- 優勢幸福力(Strength Well):56 題優勢韌力量表(9+ 優勢特質 × 心情溫度計 × 幸福感量表),**504 份樣本、三量表全面顯著相關**;滿意度近九成。
- 心理師質性觀察+解測討論=**Route C 已在運轉**(不是未來式)。
- 企業成效敘事已成立:Medialand 離職率、新人存活率、滿意度多項改善。

### 年度報告的兩大需求 ↔ 平台的正面回應
| 報告發現 | 平台對映 |
|---|---|
| 「努力被看見的渴望」+ 自我價值優勢認知不夠 | 八態(明現)/型錄「好好用」/優勢幸福力解測——**鏡·資源** |
| 「恢復能量的需求」+ 自我照顧能力不足 | 坎·沉澱/HRV/呼吸練習——**場**;「自我照顧是專業能力」即平台命題 |
| 賦能 × 餘裕(心理能量入績效管理) | 賦能=鏡+好好用;餘裕=自主感+場(JD-C:高要求×低主控權=過勞 → 練息場還給主控權) |

### 企業節奏(To-B 版的日週季年)
**年**(優勢幸福力健檢+心理師)→ **季**(八態照鏡)→ **週**(心情溫度/週五練息場)→ **日**(HRV+呼吸)。
數位工具的角色=**兩次年檢之間的連續性**——工作坊的感動不斷線,健檢的洞察有日常著力點;來年報告的「科學數據追蹤驗證」正好由此供給(匿名聚合、opt-in,即 §5 回饋迴路的 B2B 版)。

### 優勢幸福力 × 八態:並列,不融合(2026-07-08 定案)
兩者測不同的東西——優勢幸福力是實證量表(常模、跨人比較、年檢),八態是能量快照鏡(ipsative、易學語彙)。**不做量表對映**:硬對映既稀釋優勢量表的科學公信力(To-B 資產),也違反平台級 C1(跨系統不捏對應)。
整合只在旅程層:①「我的練息場」**並列**呈現兩份結果,不翻譯不互相解釋;②同一種語氣與誠實邊界;③**轉介動線**——健檢後想要日常的鏡子→八態;八態之後想要科學版的資源盤點→優勢幸福力。

## 8. 誠實邊界(平台級)

- 誠實印章是品牌資產:「v0.1 研究假設·待考」照掛。
- 鏡子非算命:個人頁任何跨工具的併陳=**並列呈現,不捏跨工具因果**(C1 的平台版——HRV 低+乾亢只能並列,不得宣稱機制)。
- 三種鏡子(自評/生理/情緒)不一致時,呈現為**反思點**,不裁決誰對。
