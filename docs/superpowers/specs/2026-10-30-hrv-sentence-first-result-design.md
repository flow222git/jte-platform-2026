# HRV 結果頁「一句話先行」設計

- 日期：2026-10-30
- 狀態：Simon 核准草案（https://claude.ai/artifact/PVfcAbnrzHQ1zsMaxQBBzs v4），採預設：語氣溫和口語、不附提醒、先不依情境標記換句子、第一次不給分數、第 7 次起畫常態範圍
- 視覺：維持 HRV 頁現有樣式

## 一、目的

一般使用者第一眼就看得懂：先用一句白話說「你看起來怎麼樣」，數字保留，但每個數字都附分區色帶與各區的意思。

## 二、版面（由上到下）

1. **一句話**（hero 卡）：主句＋副句。顏色依身體能量等級；第一次用主色。
2. **看得到的線索**：2–4 條白話，不放數字。
3. **數字和它的意思**：每個數字＝數值＋區名標籤＋色帶（標記你落在哪）＋每區一行說明（標「← 你這次」）＋「這是什麼？」。
4. **你的呼吸**：沿用「你的呼吸樣貌」卡；呼吸快慢的藍色分區放在這張卡裡，「數字和它的意思」不重複。
5. **為什麼這樣說？**（可展開）：這句話背後的數字與訊號品質。
6. 身體面相、感覺對照、標記、免責（沿用）。

移除：hero 的能量橫條、信心建立中提示、「看細項」、「身體能量怎麼分」（由 3、5 取代）、`buildPersonalAdvice`。

## 三、使用階段

以「本次之前、有 RMSSD 的 HRV 記錄數」n 判斷：

| 階段 | 條件 | 呈現 |
|---|---|---|
| 第一次 | n = 0 | 不給身體能量分數（記錄省略 `energy`/`level`，避免趨勢頁把 null 當 0）；只說這一分鐘看到什麼；恢復力、心跳不畫個人分區 |
| 建立中 | 1 ≤ n ≤ 5 | 分數標「初估」；比較對象寫「你前幾次」；恢復力、心跳不畫個人分區，顯示「再量 N 次就有你自己的分區」 |
| 常態建立 | n ≥ 6（本次為第 7 次以上） | 恢復力、心跳以個人常態範圍分三區 |

## 四、個人常態範圍

取最近 14 筆：中位數為中心，半寬＝max(相對下限, (P80−P20)/2)。RMSSD 相對下限 10%，心率下限 3 次/分。落點：below／in／above。

## 五、顏色

- 有方向的數字用紅黃綠：**黃＝跟你平常一樣、綠＝較有餘裕、紅＝較累**。身體能量 <45 紅、45–74 黃、≥75 綠；恢復力低於常態紅、高於常態綠；心跳方向相反（快於平常紅、慢於平常綠）。
- 呼吸快慢沒有好壞，用深淺藍：慢速 <8、平緩 8–12、一般 12–18、偏快 >18。

## 六、組句規則（`HrvSentence.compose`，確定性、可追溯）

輸入：階段、能量等級、恢復力落點、心跳落點、呼吸（可無）。優先序：

1. 第一次 →「這是你的第一次，先認識你的心跳。」
2. 呼吸 <8 次/分且帶動心跳 ≥ ±5 →「你的呼吸慢下來了，心跳也跟著大幅起伏。」
3. 恢復力低於、心跳慢於（偏安定）→「身體在放電，但還撐得住。」
4. 恢復力高於、心跳快於 →「恢復得不錯，但心跳比平常快。」
5. 能量平穩但恢復力低於／高於 →「大致穩穩的，只是恢復得比你平常少一點。」／「大致穩穩的，恢復得比你平常好一點。」（主句必須跟恢復力色帶一致）
6. 能量等級：充足「你看起來很有活力。」／平穩「跟你平常差不多，穩穩的。」（建立中為「你前幾次」）／偏低「身體看起來有點累。」

副句與線索由恢復力、心跳落點的固定片語組成，與色帶落點一致。用「看起來」：只反映、不預測、不給處方、不說好壞。

句子、片語、分區定義都放在 `hrv/hrv-sentence.js`（canonical 句庫），英、日文在 `hrv/index.html` 的 `JTE_I18N`。

## 七、驗證

- `hrv/hrv-sentence.test.html`：常態範圍、落點、各情境主句與副句、建立中用語、第一次不給分數。
- `hrv/hrv-result.test.html`：端到端（無歷史→第一次；預先放 8 筆歷史→常態建立）：hero 句子、色帶、記錄是否省略 energy。
