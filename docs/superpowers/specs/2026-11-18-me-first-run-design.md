# /me 第一次進來：先挑一本，再點三下

整理日期：2026-11-18 ｜ 性質：設計規格（使用者已同意方向，初版已實作）
上游：`2026-11-17-me-living-sketchbook-design.md`、`2026-11-17-platform-style-switch-design.md`、CLAUDE.md「鏡子非算命」「作答不上傳」

## 1. 要做什麼

使用者 2026-11-18：「第一次進來的人可以問幾個問題幫他建立他的首頁」「依照問題的設定跟回答，我們也可以長出不同風格的網站」。目標是大家愛用。

核心：**回答本身就是他的第一筆內容。** 問完的那一刻，手帳上已經有屬於他的東西。

## 2. 定案

- 最多三題，每題都能「先跳過」，之後都能改。
- 只問會變成內容的題目；答案只拿來排順序的題目不問。
- 「沒有」「還沒有」是正常答案，而且一樣有東西拿（三次呼吸）。
- 不是彈出的問卷視窗：首頁先是空白的，每答一題多長出一塊。
- 「風格」分三層，各有主人：

| 層 | 誰決定 | 什麼時候變 |
|---|---|---|
| 外觀（哪一本：簡潔／手帳／手繪） | 本人挑 | 他自己換才變 |
| 組成（首頁有什麼） | 他的回答 | 他加了、拿掉了東西才變 |
| 當天的顏色 | 當天選的狀態 | 只在當天那一塊 |

- 系統不依心情推測風格，不出現類型或診斷的字眼。
- 語氣（同一件事對新手、老手說法不同）這一層先不做。

## 3. 流程

| 步驟 | 內容 | 寫進哪裡 |
|---|---|---|
| 0 挑一本 | 三張封面：簡潔、手帳、手繪（手繪是使用者 2026-11-18 追加） | `jte_theme_v1`（jte-theme.js） |
| 1 現在怎麼樣？ | 五個狀態（沿用 `states`） | `jte_me_v1.states[今天]` |
| 2 你平常有在練什麼嗎？ | 例子＋瑜珈、走路＋自己打；或「還沒有」→ 三次呼吸 | 「我的練習」的項目；做完呼吸則是「呼吸・次」加今天一筆 3 |
| 3 你是怎麼來的？ | 參加過活動／朋友提過／自己逛到 | 不儲存；選「參加過活動」會確保登入邀請出現 |

回答先排成預覽，按「好，開始用」才一次寫入。寫入後 `prefs.first = 'done'`，不再問。

## 4. 什麼時候出現

- 手帳完全空白（沒有紀錄、註記、狀態、隨手記、練習項目），而且 `prefs.first` 還不是 `'done'`。
- 示範模式不出現。網址加 `?first` 可以強制再看一次（示範模式下也可以，方便檢視）。
- 第一畫面有「我用過了，直接進去」，給換裝置或清過瀏覽器的人。

## 6. 還沒做、還沒驗證

- 手寫字體仍用裝置內建字體，正式字體的授權待查。
- 手帳外觀是初版：靠共用變數換色、換邊線與標題字體；色塊的蠟筆顆粒、手繪感的膠囊按鈕還沒做。
- 第二題的選項清單由使用者決定，目前是暫定。
- 沒有真的新使用者試過。下一場活動後找三個參加者不解釋地試用。
- 首頁（平台入口）與各工具頁還沒有兩種風格（風格切換規格第 3、4 段）。
