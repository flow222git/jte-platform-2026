# HRV 結果 v2：多面相 ＋ 事後自我回饋 ＋ 生活記錄 設計 spec

整理日期：2026-06-19 ｜ 對象：`hrv/index.html`（結果頁 `renderResult` 及其後流程）、`hrv/hrv-freq.js`
目標：把單一「身體能量分數」升級成**多面相呈現**，加上**事後自我回饋**與**生活記錄**，
幫使用者把「身體量到的 × 自己感覺的 × 生活發生的」三層對照，深化覺察。定位：參考非診斷。

## 1. 新流程

量測 →（自動）算指標 → **A. 多面相結果** → **B. 事後自我回饋** → **C. 生活記錄** → **存檔（本機＋中央）** → 趨勢。

B、C 在結果頁下方，**皆可略過**（不強迫）；略過仍正常存檔（只是少了感覺/情境欄位）。

---

## 2. A — 多面相呈現（決策：D，多面並陳）

頭條維持 **身體能量**（`energyScore`）。其下並列數個「面相卡」，每張：**面相名 ＋ 一句白話狀態 ＋（微互動）「跟你的感覺對得上嗎」**。

| 面相 | 來源 | 白話 | 備註 |
|---|---|---|---|
| 身體能量／恢復 | `energyScore`（vs 個人 baseline） | 今天恢復得如何 | 頭條（既有） |
| 平靜 | 靜息 HR | 安定 ↔ 亢奮 | 既有 |
| 放鬆↔緊繃 | RMSSD | 副交感活躍、鬆不鬆 | 既有（改白話化） |
| **油門↔剎車** | **LF/HF（新接 `hrv-freq`）** | 交感↔副交感比例（備戰 vs 修復） | **新露出**；需把 freq 接進 result 計算 |
| 整體彈性 | SDNN | 整體適應力 | 新露出（次要、可折疊） |

- LF/HF 需足夠長度與乾淨 RR 才穩；資料不足時該卡顯示「這次資料不夠，下次量久一點再看」而非亂報。
- 數值一律附「相對你自己 / 參考非診斷」語氣，不下醫療判斷。

## 3. B — 事後自我回饋（決策：量完直接看、事後回饋）

結果呈現後，問 1–2 題輕量自評（點選即可、可略過）：
- **身體感覺**：放鬆 / 普通 / 緊繃
- **精神感覺**：有電 / 普通 / 累
送出後給一句**對照**：把自評對到身體數據——
> 一致：「你的感覺和身體挺同步的。」
> 不一致：「你覺得〔緊繃〕，身體量到偏〔放鬆〕——感覺和身體有時不同步，這很值得留意。」（中性、非糾正）

## 4. C — 生活記錄（決策：快速標籤＋選填一句）

- **快速標籤**（多選，預設集）：剛運動 / 剛起床 / 工作中 / 睡前 / 咖啡因 / 壓力大 / 睡不好 / 生病 / 喝酒 / 經期 / 放鬆中 …（10±，可日後調）。
- **選填一句**：自由文字（≤140 字）。
- 用途：存進每筆紀錄 → 趨勢可看「什麼情境下身體都怎樣」（趨勢標註留為輕量後續，不在本期重做趨勢圖）。

## 5. 儲存（決策：本機＋中央彙總）

- **本機**：擴充既有 HRV 紀錄物件，新增 `felt:{body,energy}`、`tags:[]`、`note`。沿用既有 history（baseline/趨勢已讀它）。
- **中央**：POST Firestore（沿用 `jointoenjoy` 專案＋REST，仿八態回饋）。集合：`hrv_log`。
  - 欄位：指標（hr/rmssd/sdnn/lf/hf/lfhf/energyScore）＋ felt ＋ tags ＋ note ＋ ts ＋（若已登入）email。
  - **隱私注意**：HRV 工具為公開（無登入閘），中央彙總屬個人生理＋生活資料 → **匿名上傳（無登入則不帶 email）**，結果頁加一行極簡告知「匿名統計，幫助我們改善」。寫入失敗不影響本機存檔（best-effort、靜默）。

## 6. 測試（無 node，延伸 hrv 測試）

- `hrv-freq` 接入：給定乾淨 RR → LF/HF/lfhf 在合理範圍；RR 太短 → 該面相顯示「資料不足」不報錯。
- 多面相卡片 render（各面相節點存在）。
- 事後回饋：選身體/精神 → 對照句正確（一致 vs 不一致分支）。
- 生活記錄：標籤多選 ＋ 選填一句 → 寫入本機紀錄物件含 felt/tags/note。
- 既有 hrv 測試全綠（含心跳偏快修正後的 14）。
