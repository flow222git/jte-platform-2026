## 3. 怎麼讀型錄(給使用者的說法)

1. **先測**:25 題,拿到你的輪廓與主峰。
2. **主峰是入口**:翻到你主峰那一卦的型錄——那就是「你的章節」。雙峰的人讀兩章,外加雙峰組合(若恰為四對待,有專文)。沒有明顯主峰的人,直接讀你的格局型(高能多面/低調蓄能/均衡)——你們不再只有一句話。
3. **能格決定讀哪段**:同一股能量,「用得剛好」與「用過頭」是兩個樣子——中正段是你的本錢,亢段是你的訊號,潛段寫給這股是缺口的人。
4. **誠實框架不變**:型錄寫的是「這股能量在這個場域的顯相」,不是「你這種人的命定」。它是圖鑑,不是判決;你是格局,不是一個卦。

## 4. 憲法相容(為什麼敢寫這麼細)

- 索引=(態×能格×場域),主語是能量不是人(R1)——不裝箱。
- 中正/亢/潛分段不混寫(C2);每句可追溯五素材(C7)。
- 跨股只在四對待,且只有雷風講張力(C1/C3)——T1 的「成長方向」一律指向錯卦搭檔之德,T3 只寫四對。
- 寫顯相不寫動機、描述不預測(C5/R5/R6)——與九型的楚河漢界。
- 每篇帶 felt-self 快照框架、價值中性(C6/C8)。
- 測試把規範鎖進 CI:growth 段必含錯卦功能名、僅 zhen-xun 帶 tension 旗標。

## 5. 與九型人格的關係(定位一句話)

九型靠「固定型+動機機制」推演內容;八態用「態×能格×場域」實寫內容。體感同樣細膩(主峰讀者讀到的就是「我的章節」),但每句可追溯、不宣稱動機、不裝箱——**細膩不減,誠實加倍**。詳見比較 spec。
