## 分歧清單

**1. 態:乾(presence 判定形式)**
- 兩邊判定:A 未明判(僅④「定向的話語有料且集中於同一人身上」帶過)/ B 有料(③,附「這個市場還沒有人真正做過…」「首年目標是 20 家事務所簽約,這個數字就這麼定…」兩則具名引文)/ 答案卡:有料。
- 兩邊引文:A、B、答案卡三方引用的原文完全相同,無引文分歧。
- 研判根因:非引文抓錯層、非素材埋太淡——三方對哪兩句算乾的證據完全一致。根因是 output_spec 的報告結構(①缺席→②失衡→③強態→④系統小結)沒有明訂「不落在①②③任一段的態,該在哪裡下正式 presence 判句」;A 只把乾放進②失衡疑似段(見分歧4),卻從未給出乾本身的 presence 判定。

**2. 態:震(presence 判定形式)**
- 兩邊判定:A 未明判(僅④「下一步動作只有一處具體紀錄」帶過)/ B 薄(③附加小節,引文「下週先跑 5 家事務所試用,由徐子昂帶隊」與答案卡逐字相同)/ 答案卡:薄。
- 兩邊引文:三方一致。
- 研判根因:同分歧1,output_spec 結構缺口——「薄」態(不缺席、不失衡、不夠強)在 A 的輸出裡沒有任何段落容身。

**3. 態:坤(presence 判定形式)**
- 兩邊判定:A 未明判(僅④「兩行薄薄的安排」帶過)/ B 薄(③附加小節,引文「營運由 Amy 接」與答案卡逐字相同)/ 答案卡:薄。
- 兩邊引文:三方一致。
- 研判根因:同分歧1、2。

**4. 態:乾(失衡疑似,超出答案卡,A+B 皆標)**
- 兩邊判定:A 失衡疑似(②)/ B 失衡疑似(②,自行加註「唯目前僅兩筆資料,列為疑似觀察」)/ 答案卡:僅判有料,未升級失衡。
- 兩邊引文:三方同一組引文(「這個市場還沒有人真正做過…」「這個數字就這麼定,達不到算我的責任」,皆陳品睿)。
- 研判根因:非引文抓錯層、非素材埋太淡——是「同一組引文是否跨過失衡門檻」的判斷分歧。schema 乾失衡素材形狀「每次定向都來自同一個聲音」,對「四人新創、單一具名創辦人拍板」的正常早期結構與真正的「異見無入口」之間沒有區分門檻:小團隊+單一創辦人發言幾乎必然字面符合。素材並無「異見被壓下」「決策管道不開放」的積極證據,答案卡因此不升級;兩個獨立 agent 卻都從字面符合直接跳到失衡疑似——獨立收斂到同一個過度標記,顯示是失衡門檻定義不明的系統性拉力,非單一 agent 噪音。合成素材本身也有貢獻:全篇定向發言確實只給了同一人(素材側效應),但即便如此,「集中」與「壟斷」的差異仍該由 schema 門檻講清楚。

**5. 態:坤(失衡疑似,超出答案卡,僅 B)**
- 兩邊判定:B「坤:疑似無界線承接」(②,引週會議程二林詩涵對三項新增需求的回應「好,那也放進規格」「一起做,列進下一版」「可以,也加進去」)/ A 未標(僅④敘事提及坤薄)/ 答案卡:坤=薄,未列失衡。
- 研判根因:引文抓錯層——B 引的這組引文,答案卡與兩個 agent 在①都拿來判「艮缺席」(範圍擴增無人喊停)。坤的分支角色是「決定之後接住落地執行」,素材裡真正屬於坤的證據只有「營運由 Amy 接」一句。B 把「要不要做」的範圍決定證據,挪去支撐「決定之後誰來扛」的執行層失衡,跨錯分支角色。追根究柢:艮低載信號「什麼都答應;範圍只增不減」與坤失衡素材形狀「『好,我來』的頻率遠高於『這我接不了』」字面高度相似,schema 卻沒有一句話講清楚兩者證據來源的差異——混淆對照缺一條,值得回填。

**6. 態:震 vs 坎(非本次直接判錯,carry-over v0.2 note 落地評估)**
- 現況:本次乾跑震、坎無人判錯(B 明判皆中;A 雖未明判但引文與敘事方向未混淆)。
- 但震的唯一引文「下週先跑 5 家事務所試用」帶「試用」字樣,恰落在「震(尚未發生的下一步)」與「坎(已產出的驗證資料)」邊界上——素材若改寫成「上週跑了 5 家,發現 X 問題」,同一事件即從震滑向坎。目前震、坎的混淆對照互無對方條目,是真實缺口。
- 研判根因:混淆對照缺一條(前瞻性補上,呼應早前審閱 carry-over note)。

## 處置

**分歧1、2、3(乾/坤/震 presence 未明判)→ 記錄,schema 提案(非混淆對照範圍,不在本次修改,留待 controller):**
> 建議 `output_spec` 補一句:「不落在①缺席/②失衡/③強態任一段的態,仍須以獨立小節逐態列出 presence 判定+引文(八態逐一列 presence),不得僅在④系統層小結敘事帶過。」agent B 自發的「其餘 presence 記錄」小節即為可直接採納的格式先例。

**分歧4(乾失衡疑似,超出答案卡)→ 記錄,schema 提案(乾自身失衡門檻問題,非與他態相混,不屬混淆對照範圍,留待 controller):**
> 建議 `qian.失衡信號` 附加門檻限定:「單一創辦人/小團隊結構本身不足以判失衡疑似;需另有『異見被提出但未進決策』或『決策管道對他人不開放』的積極證據方可標記。」同時記錄:合成素材全篇定向僅出自一人,屬素材側效應,下輪素材宜埋一處他人參與定向的對照句。

**分歧5(坤失衡疑似,僅 B)→ 回填混淆對照(本次執行):**
> `kun.混淆對照.vs_艮`、`gen.混淆對照.vs_坤` 擴寫,補失衡層判別:「都做」若證據只到範圍決定(要不要做)=艮低載;需另有承接執行的超載證據(誰來扛、扛不扛得完)才構成坤失衡。

**分歧6(震 vs 坎,carry-over)→ 回填混淆對照(本次執行):**
> 新增 `zhen.混淆對照.vs_坎`、`kan.混淆對照.vs_震`:未來式的下一步計畫=震,已產出的驗證資料/失敗紀錄=坎。
