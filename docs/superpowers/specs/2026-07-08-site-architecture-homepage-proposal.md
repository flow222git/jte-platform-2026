前提:**第一原則——整體感,不硬整合**(CLAUDE.md)。本提案的一切「架構」都是動線與語氣的整體感,不是功能面的強制合併。

## 1. 架構觀:三層淺結構

> 每個工具維持**自己完整的世界**(不硬整合);網站給的是**門、家、路**(整體感)。

```
第一層 · 門     /(首頁)——前門三態分流+場域地圖;30 秒內被接住
第二層 · 工具   各工具獨立完整(octenso/hrv/bsrs/ven-i/BreatheAware/xiaoqi/…)
                互不內嵌、互不加對方選單;只在「對的時刻」放一條轉介線
第三層 · 家     /me(我的練息場,動工①)——localStorage 聚合的個人頁
```

**導覽哲學**:淺。全站共用的只有「回首頁」與「我的練息場」兩個錨;不做全站大選單(大選單=硬整合的第一步)。工具間的連結一律是**情境轉介**(如八態報告的三個方向→對應呼吸法),不是導覽列。

## 3. 首頁設計(原型已建)

結構由上而下,對應「30 秒被接住 → 3 分鐘找到門 → 想深再深」:

1. **開場**:円相+「看見你的能量,選擇你的流動,練。」+誠實一行(鏡子非算命)。
2. **前門·三態分流(互動核心)**:「此刻的你,比較像哪一種?」——空了/太滿/卡住 三卡,點開即給「一句理解+兩扇門」(空了→HRV/恢復呼吸;太滿→小憩卸壓/喊停練習;卡住→八態深鏡)。不需先懂任何理論。
3. **場域地圖**:鏡·照見/場·練習 兩組工具卡(沿用現行首頁的卡片語彙,八態能格加入「鏡」組之首);問易以「遇到具體處境時」的情境語擺在鏡組。
4. **我的練息場**:一張安靜的預告卡(動工①後變入口)——「你的紀錄、你的節奏,都在這裡」。
5. **企業一列**:低調的 To-B 帶(工作坊+健檢),連 jointoenjoy.com——並列,不搶 To-C 的家感。
6. **頁尾**:誠實印章+鏡子非算命。

**不做**:輪播、彈窗、全站選單、任何工具的功能內嵌。首頁是門廳,不是展示櫃。

## 4. 與現行首頁的關係

- 演進不推翻:工具卡語彙、沉靜視覺全部沿用;新增的是**前門分流**與**八態入列**,搬走的是日曆/打卡(它們屬於「家」/me,不屬於「門」)。
- 原型以 `home-2026-proposal.html` 並行存在,看過討論定案後才動真正的 `index.html`。
