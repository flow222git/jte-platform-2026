## 0. 核心問題

模型掛「八卦」之名，但若解讀只憑心理直覺、不對照卦德/五行/對待學理，會產生似是而非（例：把「兩高」一律說成「張力」，但學理上只有雷風相薄帶鼓盪；把「坎」說成沉澱，用的其實是水德而非坎卦德）。

## 1. 雙層架構（定錨原則）

- **🔧 引擎／資料層：學理完整、全部保留。** 每一態帶齊源頭：卦德、五行、先天對待關係、爻位（潛/中/亢）。是「真理來源」，不簡化、不丟失，任何表層說法都能回溯對得上。
- **🪞 表層／解釋層：走 C（混合）。** 對使用者以**五行能量的溫和、現代覺察語彙**為主，**附學理註腳**讓深究者對得上源頭；並**誠實標明**「取的是**象與五行能量**，非卦爻吉凶斷法」。守「鏡子非算命」。
- **似是而非的防線**：表層每一句，引擎都有學理撐著；表層不宣稱超過其根據（不做卦爻占斷、不做命理吉凶）。

## 3. 四對待 → 各狀態的表層解讀原則

引擎存「對待關係」；表層的**兩高**依關係分流——**只有雷風相薄帶「鼓盪/張力」，其餘三對是和諧的完整/相成/流通**（此為昨日「兩高張力是否存在」的學理結論）。

每對五態：兩高 / 偏左 / 偏右 / 兩低 / 中性。

### 天地·建構（**定位**）開創↔承接
- **兩高**：主導與承接俱全、各安其位 → **完整的格局**（能開能納，定位分明）。**非張力**。
- **偏開創**：善開局定向，較少承接託底。
- **偏承接**：善接納穩底，較少自己開局。
- **兩低**：建構系統休眠（少主導也少承接）→ 待開發、可塑。
- **中性**：開與承視情境彈性調用。

### 雷風·推動（**相薄**）行動↔拓展
- **兩高**：行動與拓展相互鼓盪、動能加乘 → **很強，但留意過衝、停不下**（**唯一帶張力/鼓盪性格**）。
- **偏行動**：衝得快、起得猛，較少鋪開。
- **偏拓展**：善鋪開觸及，較少臨門落地。
- **兩低**：推動系統休眠（動能少）→ 蓄勢、待啟動。
- **中性**：動與展彈性調用。

### 水火·認知（**不相射**）沉澱↔展現
- **兩高**：內沉與外顯並存而不相礙 → **既深又亮（如「既濟」之相成）**。**非張力**（水火不相射、不相熄）。
- **偏沉澱**：向內深、收，較少外顯。
- **偏展現**：向外亮、表達，較少沉澱。
- **兩低**：認知系統休眠 → 待點亮。
- **中性**：收放彈性調用。

### 山澤·調節（**通氣**）喊停↔交流
- **兩高**：收界與往來之間氣機流通 → **進退有節、調節健康（通氣）**。**非張力**。
- **偏喊停**：善守界線/收，較少往來。
- **偏交流**：善往來連結，較少設界。
- **兩低**：調節系統休眠 → 待建立節奏。
- **中性**：進退彈性調用。

## 4. 能格：潛 / 中 / 亢（接物極必反）

引擎存每卦的「亢（過用）／中（中正/時中）／潛（不足）」失衡樣態（見表 §2）。表層：
- **過用＝亢**：物極必反、過猶不及（例：乾亢＝亢龍有悔）。對應既有 `costVerdict` 的 aOver。
- **適中＝中正/時中**：強而剛好、當位。
- **不足＝潛**：潛龍勿用、還沒長開。對應 aUnder。

能格與「相對形狀（ipsative）」是兩件事：能格＝對照自己對該股的「使用程度」（過/中/不足）；形狀＝相對自己各股的高低。兩者並存、不互斥。
