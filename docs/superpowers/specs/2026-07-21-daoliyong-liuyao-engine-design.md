## 0. 緣起與定體（使用者 2026-07-21 定案）

- **立案動機**：v3 首判（A 集團）出現本卦分歧——道爻「剛亢」（對內自驅）與「柔溺」（對外被牽走）皆有引文，三爻卦只有一個道爻，兩讀互相擠壓。六爻（內外分池）結構性化解：內乾外兌＝**夬卦**（64 表 #43），彖「健而說，決而和」——內健外悅正是兩讀共同指向；召喚「戒備（艮）」與①④判得的艮薄互證；召喚「公開告眾（兌·離）」與 v3 之卦菜單（兌／離）一字不差。手演即立案證據。
- **排法 B 寫死**：下卦＝內在運作的理用道、上卦＝對外運作的理用道。六爻卦＝內模式 × 外模式——**八態是六爻的字母表**（內外卦各自是 MODES 八腳本之一，直接可引）。排法 A（原典三才式：初二理／三四用／五六道）留作學理註腳（萬物對應圖溯源），不入引擎。
- **階梯**：三爻＝預設（底層解釋）；六爻＝厚素材自動升級（兩池門檻過才升），不用使用者選。
- **雙觀並陳**（v3 分歧的正式化）：⑤量形圖＝相對形勢觀（presence 三段）、⑥判卦＝絕對質性觀（剛柔）。兩觀分歧處必須明文並陳——分歧本身是診斷（例：形似兌、質判乾＝餘地被剛性吃掉，趨韓非形的機轉）。剛柔判準補「絕對質性判定，非相對比較」條款。

## 1. 內／外證據分池規則（判準級，已核准）

- **內池（→內卦／下卦）**：判讀對象**內部**的運作——成員彼此如何對待、內部流程與制度、內部文化語言、自我要求與自我對話、內部資源調度。
- **外池（→外卦／上卦）**：判讀對象**對外部世界**的運作——對客戶／市場／合作方／公眾的行為與姿態、對外承諾與表達、對外部環境變化的應對。
- **歸池三原則**：
  1. 以判讀對象為界，界隨對象移動（對象＝集團：員工彼此＝內、客戶＝外；對象＝某 BU：其他 BU＝外）。
  2. 每句引文歸一池，歸池理由可追問（G5 延伸：引文＋歸池依據）。
  3. 模糊句以「行為的受向」判——動作作用在誰身上就歸哪池。
- **升級門檻**：兩池各自撐起三爻剛柔判定（六格各附引文）→ 成六爻；任一池不足 → 退回三爻版（全素材合池，即 v3 現行），明文註記「六爻不成——某池證據不足」＋補問。

## 2. 六爻判定與變爻規則（已核准）

- 六格＝內理／內用／內道／外理／外用／外道，各判剛柔＋安動（沿用 v3 已核准之剛柔判準三表與亢／溺信號；每格附逐字引文＋歸池依據）。剛柔判準補註：**絕對質性判定，非相對比較**（亢／溺混淆對照另補：判別＝動力來源——自驅過極＝亢、被外牽走＝溺）。
- 剛＝陽、柔＝陰；內三爻反查 `guaOf` 得內卦、外三爻得外卦；六爻卦＝內卦×外卦，以卦名（內·外）查 64 需求表。
- **動爻規則**：
  1. 動爻照實全列——幾個動就列幾個，各附「何以見動」引文，不隱藏不挑選。
  2. 轉化菜單＝每動爻一條路（該爻翻轉 → 之卦，64 表反查），附適用時機；**宣告裁決優先**（有目標／TA → 引擎聚焦一條並說理由），無宣告 → 菜單並列（G8 不猜）。
  3. 動爻 ≥ 4 誠實加註：「局勢多處臨界，菜單失焦；建議宣告目標聚焦，或先處理①–④缺席警示再回來看卦」——不發明亂局占法、不硬給答案。
  4. 靜卦（零動爻）：本卦即安，無轉化建議，只給 64 表卦旨與召喚／節制作為維持參考。
