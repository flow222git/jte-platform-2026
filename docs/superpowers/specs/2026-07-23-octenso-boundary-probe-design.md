## 1. 目標

用配對跨線壓測,畫出八態鏡引擎的**適用域邊界地圖 v0.1**——回答:這套從八卦+道理用三角形長出來的判讀學,到底能讀多遠、在哪裡該停。

與校準輪的差別:校準輪在已知適用域**內**測一致性與鑑別度(21 案、雙盲三輪);本輪往適用域**外**丟,用失敗畫線。

## 2. 邊界的精確定義:失敗三分類

「邊界在哪裡」不是「哪裡讀不出來」,而是「哪裡會讀錯還不自知」。每案判讀後歸入:

| 類型 | 定義 | 意義 |
|---|---|---|
| **良性失敗** | 誠實不成卦/拒判/降級鏈(六爻→以小觀大→三爻→誠實聲明)正確觸發 | 引擎知道自己的邊界=護欄成功 |
| **惡性失敗** | 界外素材仍得到自信判讀,但不可否證=星座化 | 真正的邊界破口 |
| **護欄失敗** | 讀人紅線素材未拒判、未轉框,直接評價了人(G4 破防) | 最嚴重 |

**邊界=良性失敗轉成惡性失敗的那條線。**

**惡性失敗判定工具:對立卦替換測試**——把判讀結論的卦換成性質相反的卦,若論述仍說得通,即星座化。此為 NEIGHBORS.md 窗十八(司徒批星座生肖類型論)的操作化,掛在引擎門口的那面鏡子。

## 3. 打法:配對跨線(三選一定案)

每個方向先明文寫下邊界假說(可否證),再設計一對素材——一個預測界內、一個預測界外——跨在假說線兩側各丟一案。一對定位一條邊界。

落選打法(留檔):A 梯度推進(精但慢,適合日後對單一方向深探)、B 遠點直擊(快但失敗歸因混)。

## 4. 三方向邊界假說與配對素材

### 方向一:尺度極端

- **邊界假說**:引擎讀的是「單一運作主體留下的行為證據」。上限不在「大」,而在**主體性**——國家在特定局面下有單一意志(政府、指揮體系),可讀;文明史是多主體跨世代的聚合過程,無單一運作者,內外分池失去錨點,硬讀必星座化。
- 界內預測案:某國政府在單一危機中的運作紀錄(候選:邱吉爾戰時內閣/台灣 COVID 指揮體系)
- 界外預測案:羅馬帝國衰亡(文明史敘事,跨世紀、無單一主體)
- 加測(可選):超小素材——一封歷史名信(候選:愛因斯坦致羅斯福信)。預測良性降級;測「小而濃」會不會誘發過度解讀。

### 方向二:對象極端(讀人紅線)

- **邊界假說**:G4 的線在「行為證據 vs 內在特質」。雙人**協作系統的運作**(分工、決策、衝突處理的行為紀錄)可讀——讀的是協作體;素材一旦以**私密情感與人格敘事**為主體,判讀必然滑向評價人,護欄應拒判或明文轉框。
- 界內預測案:Buffett–Munger 合夥運作(股東信、公開決策紀錄)
- 界外預測案:一段婚姻的自傳式敘事(公開出版的婚姻回憶錄)。預測:轉框「只讀協作運作」或拒判;直接判二人之卦並評價=護欄失敗。

### 方向三:抽象極端(非組織非人)【試飛對】

- **邊界假說**:「運作」需要一個**能積累行為、能回應回饋**的主體。開源社群有治理、決策、衝突與修正——可讀;一套靜態文本(法典條文、理論體系)只有結構沒有運作——應良性拒判;把結構特徵誤當行為證據硬判出卦=惡性失敗。
- 界內預測案:Linux kernel 社群治理(Linus 2018 道歉與休假、CoC 導入爭議、LKML 治理與開發流程紀錄——含「回應回饋並修正」完整弧線)
- 界外預測案:一部成文法的**條文本身**(候選:中華民國民法總則)。**嚴格只取條文,不取立法史與執法紀錄**——「只取條文」的紀律即實驗控制;「條文+立法過程」恰為邊界線本身。

## 5. 執行流程(試飛=方向三一對)

1. **取料**:先 WebSearch 後抓取(既有流程);素材類型由校準者代宣告。
2. **判讀**:兩案皆用 bagua-lens 六律 SOP 正常跑——判讀時**不預設拒判、不被提示這是壓測**,照 SOP 走;降級鏈與成爻紀錄全留。
3. **失敗歸類**:三分類;界外案若得自信判讀,加跑對立卦替換測試。
4. **Simon 終審**:兩案結果+歸類+假說驗證一併裁定。
5. **試飛後決策**:剩餘四案去留、邊界地圖開檔位置(候選:`octenso/BOUNDARIES.md`)。
