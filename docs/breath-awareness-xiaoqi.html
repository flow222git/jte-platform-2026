兩支柱的完整介紹、產品化藍圖，與落地優先的策略

練息場 · 照顧自己的家

真實老師 × 誠實深度 × 日常習慣　·　我們做的是鏡子，不是算命。
呼吸，是每個人隨身、免費、最低門檻的自我調節入口——也是我們「每天回來」的心跳。

為何從「呼吸」開始

在所有身心工具裡，呼吸的門檻最低、可及性最高、又有清楚的生理根據。

零門檻

不需器材、不需場地、不需先懂理論。任何人、任何時刻都能開始——這讓它天生適合當「日常高頻」的入口。

有生理根據

呼吸是我們唯一能「自主操控」的自律神經開關。延長吐氣、放慢節奏，能實際影響心率與情緒——可被感受、也可被量測。

誠實不玄

它不預測命運、不販賣神秘。它只是把你帶回當下的身體。這正呼應練息場「鏡子非算命」的核心。

兩根平行支柱

同樣是呼吸，我們把它拆成兩種截然不同的使用方式——「隨時覺察」與「定時練習」。

支柱一

呼吸覺察

隨時 · 一種能力

日常隨時、微觀察自己的呼吸與狀態。不必開 App、不佔時間，是一輩子帶著走的能力。產品的角色是「提醒你想起它」。

支柱二

小憩

定時 · 一段練習

定時坐下來的一段引導呼吸練習——有引導、有長度、有節拍。已有實作成品「小憩。練息」App。產品的角色是「陪你好好練這一段」。

＊兩者互補：覺察讓你「發現此刻需要」，小憩讓你「認真給自己一段」。一個是日常肌肉，一個是定時充電。

這頁在講什麼：呼吸覺察是「一種能力」，不是一個功能。它為何有效、長什麼樣子，以及我們如何把「一種能力」設計成產品。

是什麼

呼吸覺察，是在日常任何時刻，把注意力短暫地放回自己的呼吸與身體狀態：現在我的呼吸是急是緩？肩膀是不是聳著？我此刻是「上緊」還是「掉電」？

它不是一段要完成的練習，而是一種會越練越靈敏的覺察能力。它不需要 App、不佔時間——三秒鐘也算。它的價值，在於讓你「在被情緒帶走之前，先看見自己」。

為何有效

呼吸是身心之間的雙向開關。看見它，就多了一個調節的把手。

看見即介入

光是「注意到自己正在淺快呼吸」，往往就會自動變慢。覺察本身就是第一步調節，不需要任何技巧。

從自動到自主

情緒上來時我們容易「自動反應」。覺察在刺激與反應之間，撐開一個微小的空隙——那個空隙就是自由。

隨時覺察的樣貌

它發生在生活的縫隙裡，不在坐墊上。

塞車、等紅燈時 會議 / 上台前 打開訊息、感到胸口一緊 排隊、等電梯 睡前躺下的第一分鐘 情緒被戳到的當下 切換任務之間

＊共同點：這些都是「不會特地開 App」的時刻。所以呼吸覺察的產品設計，重點不是把人拉進 App，而是讓人在離開 App 時把能力帶走。

如何把「一種能力」變成產品

挑戰：能力無法被下載。我們能做的，是設計「想起它」的觸發、與「越練越強」的回饋。

提示（想起它）

  • 八態電量 check 後，順勢遞出「此刻做一次覺察呼吸」的一句話
  • 選擇性的溫柔提醒（例如午後掉電時段），不打擾為原則
  • 鎖屏 / Widget / 通知一句話，把覺察帶出 App

微互動（10 秒內）

  • 「三口氣」的極短版：不進練習頁也能做
  • 一句自問：「現在呼吸急還是緩？」＋一次記錄
  • 覺察不等於練習——刻意保留「秒完成」的入口

習慣（越練越強）

  • 把「今天覺察了幾次」變成可累積、可回顧的軌跡
  • 感受標籤：覺察前 vs 覺察後，看見自己的變化
  • 連續天數 / 溫柔的回訪，強化日常肌肉

教育（懂得用）

  • 用一句話、一張圖說清楚「為何有效」，去玄化
  • 把覺察嵌進真實場景（開會前、睡前）的微內容
  • 老師 / 內容把覺察示範出來，讓人模仿
這頁在講什麼：小憩＝定時坐下來的一段引導呼吸練習。我們已經有一個做出來的成品 App——先盤點現況，再談體驗哲學與往哪深化。

是什麼

小憩，是定時給自己的一段引導呼吸練習。與「隨時覺察」不同，它是刻意坐下來、有引導語、有呼吸節拍、有長度的一段時間——從 3 分鐘的三口呼吸，到深度的重生呼吸。

它的精神是「ONE PAUSE · ONE PEACE」——一個暫停，一個平靜。

體驗設計哲學

小憩的美學就是它的功能——安靜、留白、不催促。

畫面即呼吸

用色塊與光暈的漲落當引導，而非冷冰冰的計時器。看著畫面就會自然跟著呼吸。

少即是多

一次只做一件事，不塞資訊、不比較、不遊戲化過頭。安靜是刻意的設計。

選對，不選多

用「情境」而非「技巧名」分類，讓人依當下狀態選，而不是先懂理論。

從現況再往哪走

現況扎實，深化方向見 Tab 04 產品化藍圖。這裡先點出三個機會缺口。

推薦

目前靠人自選。若接上「八態電量」或當下感受，就能幫你選對那一個。

回訪

純本機、無提醒。缺一個「會回來」的溫柔鉤子與跨裝置延續。

成效可見

有感受標籤，但還沒把「練習↔狀態變化」連成一條可回顧的成長線。

這頁在講什麼：從「已有一個好用的小憩 App」到「練息場每天回來的入口」。功能路線圖依優先序排列，落地優先。

現況 → 目標

現況

  • 一個做得漂亮、可用的小憩練習 App
  • 純本機、單機、無帳號
  • 靠使用者自己選呼吸法
  • 覺察能力尚未被產品化

目標

  • 練息場「每天回來」的日常入口
  • 覺察（隨時）＋小憩（定時）兩支柱並存
  • 依狀態幫你選對那一段
  • 看得見自己的成長，願意回來

功能路線圖（依優先序）

先把「入口 × 選對 × 回來」跑順，再談整合與規模。

P0 · 把地基打牢先做
  • 呼吸覺察「秒完成」入口：三口氣微互動 + 一鍵記錄
  • 練習後 → 感受回饋（前後對照），串成可回顧軌跡
  • 資料延續：帳號 / 雲端同步（現為 localStorage，換裝置即遺失）
P1 · 幫你選對接著
  • 「今天你的電量？」八態 / 三態 check → 推薦此刻該做哪一段
  • 情境化首頁：依時段 / 狀態動態排序呼吸法
  • 溫柔回訪：可選的提醒、連續天數、回來的鉤子
P2 · 接上身心錨再來
  • HRV 生理錨：把「調節有沒有發生」變得可量測（耗竭那一態可被看見）
  • 覺察 × 小憩 × 八態串成一條「看見→理解→調節」的個人線
  • 「我」單元：趨勢與成長，你看著自己變化
P3 · 規模與生態之後
  • 老師 / 內容：引導語音、客製練習、連載欄目
  • 內容可被策展、可被追蹤，接上練息場社群
  • 為 B2B（企業席位）預留的資料與管理層

與練息場其他層的整合

呼吸不是孤島，它是「看見→理解→調節」鏈裡的調節端。

看見HRV · 八態電量 check · 數位衡鑑
理解八態能格 · 問易 · 能量管理
調節呼吸覺察 · 小憩 · 聲音／茶／戶外

＊呼吸是「調節」裡最日常、最可規模化的一環——它是把人每天帶回練息場的心跳。

定位與差異化

同樣做呼吸 / 正念，我們的差異在「誠實」與「可量測」。

練息場 · 我們

  • 誠實的身心科學：鏡子，不是算命
  • 可被感受、也可被量測（HRV 生理錨）
  • 真實老師與社群，不是冷冰冰的工具
  • 覺察＋小憩＋八態，一條「看見→理解→調節」的路

常見替代品

  • 純冥想 App：內容多，但難連到「我現在如何」
  • 算命 / 玄學：給答案，但無法量測、易依賴
  • 穿戴裝置：只給數字，缺調節與陪伴

商業模式

先把 B2C 的愛做深，B2B 再騎上被愛的品牌。

先 · B2C（守黑：為個人的愛而生）

  • 免費入口：覺察微互動＋基本小憩，養日常習慣
  • 訂閱：完整呼吸法、個人趨勢、進階引導與內容
  • 課程 / 體驗：能量管理、線下體驗日（premium）
  • 老師導生 · 分潤

後 · B2B（先按住）

  • Calm / Headspace 路徑：公司買席位、員工真的愛用
  • 企業員工身心方案：以「可量測成效」當賣點
  • 先把 B2C 的品牌與留存做起來，再往上騎

落地路徑 · 下一步

建議接下來這樣走

  1. 對齊本文件：團隊看完，確認兩支柱定義與優先序沒有異議。
  2. 做 P0：覺察秒完成入口 ＋ 練習後感受回饋 ＋ 資料延續（帳號 / 同步）。
  3. 接上八態 check：讓「今天你的電量？」能推薦此刻該做哪一段（P1 的核心）。
  4. 定義指標並開始量：回訪、完成率、前後感受變化——先有數字，才談成效。
  5. HRV 小規模驗證：驗證「調節可被量測」這個差異化是否成立（P2）。
