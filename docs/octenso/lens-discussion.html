一

這面鏡子是什麼

一句話:八態鏡拿八態 × 道理用三角形當固定構面,讀一份素材裡的「運作」,輸出可追溯到逐字引文的映照——不評成敗、不判人、不預測。

它跟測驗端(八態能格)是兩件事、同一個家。平台第一原則講整體感不硬整合,這裡是最典型的一組:兩邊共用八態語言與誠實邊界,但輸入、對象、輸出各自獨立,不做量表對映。

八態能格(測驗端)八態鏡(透鏡端)
讀什麼人的自我感覺一份素材裡的運作
輸入25 題六點自評會議紀錄 / BP / 制度 / 觀察筆記
輸出八態剖面 + 格局 + 三拍解讀八態在場缺席 + 三角形體檢 + 判卦與轉化參考
誰在判規則引擎(確定性)AI 判定 + 機械推導(每條附引文)
場景讀法正向心理學讀法(先正面)吳怡版(坎=度險維心、震=謀定後動、離=附麗虛己)
共同紅線不預測成敗(G1)· 主詞不是「這種人」(G4)· 無引文不判定(G5)· 不排名不評分(G6)

目前狀態:內部工具。octenso/bagua-lens.html 掛 noindex、未接導覽、走登入閘,2–3 人使用;素材與報告不上傳不儲存(Worker 即時判讀不落檔),結果只留 localStorage。另有 skill 版 .claude/skills/bagua-lens/,判讀在對話裡跑,真相源可抓 GitHub raw,更新一處全部跟上。

定位討論:二元引擎(2026-07-28)

八態鏡+哲學三角是試圖把二元世界更完整解讀的引擎,藉由各種素材的學習,去理解二元的特性定義變化而不斷迭代自己並完整呈現照看解析的過程。 Simon,2026-07-28 · 原話照抄,未潤

這句話技術上站得住,而且已經長成 schema 的形狀:剛=陽、柔=陰,每爻判的就是一個二元;三爻二元組合成八態,六爻內外分池組合成 64 卦。二元確實是原子。句中三個詞各自對得上一個區塊——

  • 特性 → 剛柔判準三表(每爻的剛/柔/亢/溺各附樣態與信號)
  • 定義 → 歸格例句庫與混淆對照(定義的操作化;只增不減)
  • 變化 → 亢/溺 → 動爻 → 之卦(變化的機制,一爻變)

「哲學三角」在檔內的名字是道理用三角形,與八態的關係已定於憲法增修:三角形為體、八態為用,縱軸三層 × 橫軸八態=引擎核心。

三處要收緊,否則會踩到自己立的線:

  1. 「更完整」的合法意思是構面不漏,不是結論完整。引擎保證的是八態一態不可省略、三層一層不可省略、缺席也要列出來、未及之層明寫「素材不及,待補」。完整的是缺口清單,不是照出多少——「不成卦是有尊嚴的輸出」整條紀律靠這個區別站著。
  2. 「藉由素材的學習」不是模型餵養。素材不入 git、Worker 不落檔;累積下來的是被判讀分歧逼出來的判準修訂,而且逐條經人核准、G1–G8 凍結。準確的說法是:素材過鏡不留檔,留下的是判準。寫模糊會直接和「作答不上傳」那條北極星打架;核心凍結反而是迭代可信的前提。
  3. 二元要留逃生口,而且已經留了。爻疑兩讀並列、薄、缺席、不成卦——引擎明文允許二元判不下去。這正是與星座式二分法的分野(NEIGHBORS 窗七的自我警惕、窗十六的張力不壓平)。定位句若不寫這一層,「二元引擎」會被聽成更精緻的二分法。
候選定位句 · 待核准

八態鏡以剛柔二元為原子、以道理用三角形為縱軸、以八態為橫軸,把一份素材的運作攤成不漏構面的映照。它不追求把話說滿,而追求每一格都指得回原文,指不回就明說沒有;二元判不下去時兩讀並列,不硬選。它的迭代不來自素材本身——素材過鏡不留檔,留下的是被分歧逼出來的判準。

狀態:原始 · 待審閱(未入 canonical)。此為定位敘述,非效度宣稱;schema 仍掛 v0.1 研究假設·待考。另一處用詞待定:「照看」——照=映照無虞,「看」若被讀成照護,會碰到「八態鏡非治療」的紅線;候選改「照見」,或在文案裡把它定義死。

二

一次判讀怎麼跑

SOP 十二步,分取料 / 讀規則 / 判定 / 推導 / 輸出 / 品管六段。以下是操作地圖的濃縮,細節以 daoliyong-lens-sop.md 與 schema 為準。

素材進場→宣告(不猜)→載入真相源→逐句歸池歸格→六格判定→成卦或降級→機械反查→交叉驗證→動爻與轉化→報告組裝→三值回饋

宣告在前,不猜(G8)

必宣告兩項:素材類型(brainstorm / decision / retro / routine / bp / policy / interview / observation 八型)與判讀對象。可選兩項:目標與 TA——宣告越齊,第⑥段越準;沒宣告就不猜,寧可先問一句。另附次型註記(宣言型 / 調查型 / 內部報告型 / 成功敘事型 / 法規理論文本型),各自帶偏置聲明,預期缺席不列病理。

報告六段

  1. 缺席清單——依宣告分「警示 / 本型態預期」,附補問建議。缺席優先於失衡,失衡優先於滿格(G2)。
  2. 失衡疑似——型態不適用則註明。
  3. 強態圖景。
  4. 四系統各一句小結。
  5. 三角形體檢——理 / 用 / 道逐層 presence + 逐字引文,一層不可省略,後接三隅箴警示與一句量形描述。
  6. 判卦與轉化參考——本卦 → 變爻 → 之卦(見第五節)。

八態要逐一列在場狀態(有料 / 薄 / 缺席),一態不可省略;引不出原文就是缺席(無資料),缺席不等於弱。收尾必附道理用總綰:三層各一句判定、樣貌、功課,末一句總綰;未及之層明文「素材不及,待補」。

雙軌輸出(2026-07-22 定案)

正式交付分兩軌:白話版給素材主人與決策者,深讀版給校準與專業用(完整判定過程)。白話版七條借金字塔原理與 Gallup 報告設計:答案先行、行動標題(只讀標題就懂全篇)、紅綠燈道理用(術語零出現)、每個發現「這代表什麼 / 該注意什麼 / 怎麼做」三件套配一句原話、先力量後缺口、技術層收進附錄摺疊區、訊噪紀律。

語氣律

準而不刺——先力量後缺口、隱喻不判死(缺口意象須與在場力量同句並呈)、想像素材主人正在讀。

判完不算完:迭代模式

鏡子靠這個變準。每次判讀後收三值回饋(很像 / 部分像 / 不太像 + 哪一條最有感、哪一條最不服,記原話與理由),分歧記進 backlog 分五類:判定分歧、語彙、schema 缺口、三層判定分歧、判卦分歧(本卦 / 變爻 / 之卦分開記,六爻另記分池歸屬)。累積後才走進化流程:提案 → 逐條核准 → 修 schema + 檢查器 → 測試全綠 → 開 PR。

四

護欄 G1–G8

硬規則,編進定義層,任何 agent 不可覆寫;對⑤⑥段同樣適用。下表為 states-schema 快照,以原檔為準。

規則怎麼執行
G1只診斷能量分佈,不預測成敗禁止成功機率、成敗預言、「這樣下去會…」句式
G2缺席優先於失衡,失衡優先於滿格報告順序:無資料的態 → 失衡疑似 → 強態
G3回溯敘事僅供教學且需標明歷史素材一律加註「回溯性閱讀,不構成因果宣稱」
G4分析單位是運作,主詞不是「這種人」合法主詞:某分支 / 某個態 / 這份文件 / 這場會議
G5無證據即無判定每條判定附逐字引文;引不出來 → 判缺席(無資料)
G6禁止輸出清單總分、排名、錄取 / 投資建議、相性分數、人格標籤
G7面試 / 人事場景降級為觀察筆記只列「已收集到 / 尚無資料」的態,提示補問,不評價;不輸出⑤⑥
G8時間視角可用,因果推移禁止禁止系統主動宣稱態序推移;宣告一律使用者說,系統不猜

三種失敗要分清楚:良性失敗=誠實不成卦 / 拒判 / 降級鏈正確觸發(護欄成功);惡性失敗=界外素材仍得自信判讀且不可否證(星座化);護欄失敗=讀人紅線素材未拒判就評價了人(G4 破防,最嚴重)。

五

判卦引擎

第⑥段從「引用兩個腳本」長成本卦→變爻→之卦,再長出六爻版。整塊掛工作假說·待收斂印章,收斂前不進正式產品文案。

必附聲明

此卦由素材判讀推導,非起卦占斷;變爻是處方,不是預言。

四律

  • 非占卜律:爻由判讀而來(每爻附引文)、變由診斷與宣告而來,無一絲隨機。
  • 機械推導律:AI 只判剛柔與安動,卦由反查表自動得出;不得跳過判定直接「感覺是某卦」。同素材同判定必同卦。
  • 主詞律:卦名給運作不給人——「此局呈乾象」可以,「你是乾卦」不行。
  • 不預測律:之卦是參考路徑,不是「將會變成」;死角是結構警訊,不是命運。

三爻 / 六爻與四階降級

素材厚時自動升六爻:內池(對象內部的運作)× 外池(對外的行為與姿態)各撐三爻,內卦 × 外卦查 64 卦需求表,再做召喚對照——64 表召喚的態 × 八態在場缺席交叉驗證,召喚而缺席=首要功課,節制而正強=第一級警訊。歸池以「行為的受向」判,界隨判讀對象移動。

撐不起來就優雅降級,四階:六爻 → 局部深探(半象 / 爻象深讀,以小觀大,明標其小)→ 三爻(全料合判)→ 不成卦。不成卦是有尊嚴的輸出,附缺哪池哪爻與補問。

判讀紀律(v0.3.1 六律 + v0.3.3 回填)

律內容
證據純化引文計入某爻前先問「這是誰的行為」;判讀對象以外的行為者(委辦方 / 供應商 / 撰稿者)之品質不得計入
成爻門檻每爻 ≥2 句獨立引文(不同段落)方成爻;孤證標「薄」不成爻
同爻雙訊號亢溺同現先重驗歸格;仍衝突=該爻判動,陰陽並列兩讀標「爻疑」,異卦則並列 + 補問
爻疑氾濫爻疑爻數 ≥3 = 主體性存疑,拒判並附拆分建議
主體同一性行為者須能對彼此的行為負責或回應(同一主體、同一時段);跨主體跨世代聚合不判
動爻上限動爻 ≥4 加註「局勢多處臨界,菜單失焦」,建議先宣告目標或先處理缺席警示——不發明亂局占法

亢與溺在過勞終點外觀相同(都停不下),判別看動力來源:自驅過極=亢(剛)、被外牽走=溺(柔)。剛柔是絕對質性判定,不與他爻比強弱,全剛 / 全柔之卦必須可達。

歸格例句庫(只增不減)

  • 「不敢休 / 筆電隨身」= 用爻亢(輸出停不下)
  • 「假期存在但無法放鬆」= 道爻(餘地機制失效)
  • 「被客戶時程牽走」= 外用溺
  • 「不知為何努力 / 意義真空」= 道爻溺
  • 「怎麼做都不夠好」= 理爻溺(根基被評價體系牽走)
  • 「無對沖的極化語言」= 道爻亢,文體不豁免(雙盲 #2 裁定)
  • 「建制描述」歸內池、「交付動作」歸外池(雙盲 #2 裁定)
六

邊界:能讀多遠,在哪裡該停

2026-07-23 邊界壓測六案,配對跨線(抽象 / 尺度 / 紅線各一對,界內界外各一)。素材皆公開文獻,可入 git。

適用域三條件

判讀對象必須同時滿足:單一運作主體 × 行為證據 × 同一時段。缺一不判。

案方向結果歸類
Linux kernel 社群治理抽象 · 界內半象 · 內兌,一動爻;兌死角=素材自點名之問題,閉環正常出判
民法總則條文抽象 · 界外證據純化全攔 + 分池失錨 → 不成卦良性失敗
邱吉爾戰時內閣 1940/5尺度 · 界內半象 · 內兌 · 靜;與 Linux 成兌×兌同象異態對正常出判
羅馬帝國衰亡尺度 · 界外形式檢查全綠,每爻跨世紀衝突訊號;可合規聚合出對立判讀半開破口
Buffett–Munger 合夥紅線 · 界內半象 · 內震 · 靜(理剛 / 用柔 / 道柔)正常出判
婚姻告白 essay紅線 · 界外G7 + G4 + G6 三重護欄疊加拒判;零運作證據護欄成功

界內三案的對立卦替換測試皆不成立(結論換成對立卦說不通=有鑑別度);界外三案無一惡性輸出。三案共同點是外池薄——公開素材天然偏內部治理紀錄。

唯一實證破口:缺主體同一性時,引擎不會停。羅馬案形式檢查全綠仍可合規聚合出對立判讀;主體同一性律已於 v0.3.3 回填為判讀紀律,但 BOUNDARIES 明記誠實拒判目前靠判讀者自律,非規則。

誠實邊界:六案樣本、每方向僅一對,邊界線是「首測定位」不是定論;界內活下來不等於適用域擴張定案。六案素材由校準者選材與代宣告,存在選材偏置;案 3 / 5 帶英雄敘事與成功敘事偏置(已於各判讀註記)。

七

學理鄰居(並列相望,不做對映)

依平台第一原則,鄰居的概念與我們的概念並列,任何「×」讀作窗戶相望,不讀作等號。判讀仍以 schema 為唯一依據。

司徒達賢(策略管理)

最強共振三窗:描述與評估分離——「策略分析應始於描述現狀」,他明文不可與評價混淆;差別在他第二步就評估成功機會,我們停在映照(G1)。星座生肖之批——他批「不可能依星座、生肖來分類」,此窗是自我警惕:卦名一旦被當標籤就踩進他批評的坑,我們的解方是逐句判定、機械推導、孤證不判。分析與結論脫鉤——他批 SWOT 式報告的結論查不回前面的分析;我們的可追溯朝過去素材。

金樹人(心理位移 / 本土諮商)

三個通道——高行健「人稱就是通道,而且不是一個通道,是三個通道」;單一視角是平面,三座標交叉才立體。繞過洞——Portia Nelson 五章自傳詩「第四章……我繞過它」,變爻的本意正是看見洞、繞過它;且轉化靠迭代不靠頓改。超越功能——榮格式的張力要留著,不壓平成折衷(爻疑兩讀並列的學理鄰居);差別在榮格承諾第三物會誕生,我們只擺好並列。

鄰居家的房間,不進我們家:成功機率語言、作戰地圖與壓制對手、判領導人的心、為素材方預設「生存獲利成長」的目的論;八態鏡非治療,不宣稱療效,不下探無意識。位移書寫若要進平台,另立工具並列轉介,不與八態鏡混併。

八

待議題

這一區真正要吵的東西。前六條有出處、在檔未結案;後三條由這一區的討論長出來,待裁。

一 · v0.2 的「達標」沒有數字在檔未結

升 v0.2 的唯一途徑是真實素材雙盲收斂達標,雙盲 #1、#2 的裁定都已回填(#2 一致率 83%),但 schema 的 acceptance 沒寫死門檻:一致率要多少、算法怎麼定(presence 一致率 × 引文重疊如何加權)、要幾份素材。要討論:把門檻寫成數字,還是明文承認它是判斷題?寫成數字才擋得住「感覺差不多了就升版」;不寫則要說清楚誰有權判定收斂。

二 · 主體同一性靠自律,不靠規則在檔未結

三 · 「設計樣態剛柔」要不要立項未立項

民法總則案的副產品:讀文本設計而非運作,剛柔並濟的設計讀之成理。BOUNDARIES 明記這與運作判讀分屬兩種判讀學、不可混池。要討論:立成獨立工具(另一面鏡子),還是就此存照不做?混池的風險是模糊「行為證據」這條適用域鐵線。

四 · 外池永遠薄在檔待辦

九 · 迭代只有收斂管線,沒有存異管線討論提出

期待是:在演進裡看得到不同視角,甚至典範轉移。但現行機制把分歧當雜訊處理——雙盲的目的是收斂,分歧的唯一去處是「回填混淆對照」,也就是被消化掉;升 v0.2 的門檻又是收斂達標。制度上獎勵收斂,不記錄被頂翻的地方。

NEIGHBORS 窗十一寫的卻是相反立場:質疑與挑戰能讓不易注意到的前提浮上檯面,而該窗的「異」欄自己就寫著「他終須收斂成一個決策;我們可並列存檔蓋待考章」——存異是寫在筆記裡的承諾,流程裡卻沒有這一格。現成證據:案 2 頂出來的「設計樣態剛柔」是真正的視角轉移候選(讀文本設計而非運作),無處安放,只能標「未立項」。

風險不是抽象的:只收斂不存異的迭代,長期會把自己推向不可否證——那正是 BOUNDARIES 對惡性失敗的定義,只是發生在制度層而非單次判讀。

要討論:分歧三分流要不要寫進進化流程?(a) 判準沒說清 → 收斂,回填混淆對照(現行唯一路徑);(b) 判準沒錯、兩讀都成立 → 並列存檔蓋待考章,即爻疑的組織版;(c) 分歧指向「這套判讀學被素材頂到了」→ 立為典範候選,獨立列冊。零件已經有三個,缺的是接成一條與收斂並行的管線:爻疑兩讀並列(單次判讀層)、對立卦替換測試(目前只用於邊界壓測,可常態化)、NEIGHBORS 引進外部典範且明文並列不對映(防止典範被同化)。另可加一種異視角雙盲:同素材、不同宣告(換判讀對象=換界),得出不同卦不是雜訊而是視角——界隨對象移動本來就是規則寫好的。
