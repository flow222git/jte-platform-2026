題本 v4 設計候選

雙極不相減 × 他評並列——兩個從鄰居看到、我們結構上做不到的東西

設計候選 · 待審 · 不動 B3
2026-08-04 · 來源:學理鄰居三 九向度氣質

這份文件把兩件事寫成候選讓人裁,沒有動任何 canonical,沒有改題本 v3。兩條都碰得到計分本體,所以走候選而非直接修訂。

第三節另記一個一直存在、但從沒被明確選過的設計立場問題。

一

候選一 · 雙極分開計分(不相減)

鄰居能表達「兩端都高」與「兩端都低」的差別,我們的 ipsative 設計表達不出來。這不是精度問題,是結構問題。

鄰居的做法

九向度每個向度分 A/B 兩端,各 4 題,分別加總、明令不相減。關鍵在解讀規則:

兩端都高,表示會依情境切換;兩端都低,表示此向度較少主導你的管理行為。 《主管帶領氣質:九向度自評問卷與下屬管理指南》

我們現在做不到什麼

八態能格是 ipsative(相對高低)。「艮與震都高」和「艮與震都低」在相對座標裡可能落在同一個位置——前者是該衝時衝、該停時停的切換能力,後者是既不推進也不設界。兩種很不一樣的人,讀出同一個結果。

這個缺口跟一條既有規則有關:解讀憲法 C3 明訂「組合僅限四對待、只有雷風可講張力」。那條規則是為了防捏因果,但它同時讓「兩端都高」這個訊號無處安放——不是不准講,是根本讀不出來。

三個方案

方案做法代價
A 全面雙極化每態拆成兩端各出題,獨立加總推翻 ipsative 本體;題數至少翻倍;報告引擎全改;B3 之後分數不可互比
B 只在四對待上加標記計分不動,四對待各加一層讀法:雙高=切換、雙低=此對不主導需要「高/低」的絕對門檻——踩到假精確之戒
C 不做明文寫進誠實邊界:本工具讀不出「兩端都高」誠實,但缺口留著
建議:B待審

B 是唯一不動本體、又能補上表達力的路。但它有一個直接的地雷:判定「雙高」需要絕對門檻,而我們的分數是相對的。

這正是待議題一(收斂指標)剛裁過的同一種問題,照同一套處理——

  • 算法定死:雙高/雙低的判定式寫進 canonical,且用個人內部的相對位置定義,不用跨人的絕對分數(例如該對兩態皆位於個人剖面的上/下三分位,且兩者差距小於以個人分布定義的量)。
  • 門檻不從空氣裡訂:先用既有作答資料跑分布,看「雙高」若照某定義會出現在多少比例的人身上。比例過高(人人都雙高)或過低(沒人雙高)都代表定義沒抓到東西。
  • 留痕:每次調整門檻要記錄理由與當時的分布。

未經資料就寫死門檻,這條不准上線。

需要先驗證的事

  • 現有作答資料裡,四對待「兩態皆高」的實際出現率是多少?(先看分布,再談定義)
  • 雙高的人在既有報告裡現在被讀成什麼?——可能已經被讀成「格局型」。若如此,本候選的價值就從「補表達力」降為「把既有讀法講清楚」。
二

候選二 · 他評並列

我們的誠實邊界一直寫著「主觀自評有天花板」,但從沒做過任何補救。這是最大的一扇窗,也是風險最高的一扇。

鄰居的做法

最有價值的是比較「主管自評」與「下屬實際感受」。
若主管自評與下屬感受不同,應優先討論具體事件,而不是爭論類型名稱。 九向度氣質工具文件

他評不是為了「校正」自評,是為了讓分歧本身成為對話材料。而這跟我們既有的機制同構:自評 × 他評的分歧,結構上等同雙盲兩個 agent 的分歧;處理原則也一樣——回到證據,不爭標籤。

三個層次(建議由淺入深)

層次做法風險
L1 像不像核對不另外施測。報告分段揭示時請對方找一個熟識者一起讀,逐段核對「像不像」,記下不像的地方最低。衡鑑式伴讀 spec 的分段核對已有此形狀
L2 他評同一份題本熟識者依同一題本作答「我看到的他」,兩條剖面並列題幹是第一人稱自述,轉他評需改寫;易被讀成評分
L3 他評獨立題本另寫一套行為描述題(我看到他做了什麼),不問特質最貴;但最接近「行為證據」的精神

他評一進來就會拉高的風險

他評極易滑成考評。這是 G6 最脆弱的一面:一旦主管可以「評」下屬,工具就變成人事工具。

  • 現成護欄已經有了:CALIBRATION 的 schema 待辦第 6 條「練息場自有 G 條款」——① 個人資料永不進績效考評 ② 只做正向分析不做反向標記 ③ 對資方僅去識別化趨勢。他評若立項,這三條必須先明文化並上線,不能後補。
  • 他評結果永不進報告的「分數」,只進「對照」。分數只有一條,就是本人的自評;他評是並排的另一面鏡子——不合成、不平均、不修正,同「並列不對映」的第一原則。
  • 作答不上傳的處置:他評必然涉及第二個人的資料,localStorage 模式不成立。這是戰略決定不是功能,要單獨過。
建議:從 L1 起,而且 L1 現在就能做待審

L1 不需要新題本、不需要後端、不碰資料回流,只是報告的一句引導語。L2 / L3 等 G 條款明文化之後再談。

三

一個從沒明確選過的設計立場

拆題還是並列——同一個問題的兩種解法,我們兩邊都在用,卻從沒說過那是一個選擇。

同一訊號有兩種合法讀法→拆題:事前消歧,換乾淨資料或並列:事後留張力,換真實

鄰居發現「低反應閾」有歧義(可能敏感於下屬情緒,也可能敏感於品質偏差),解方是拆成兩個問法。我們遇到同型問題的解方是爻疑並列。

兩種都合法。但我們從來沒有明確選過——而題本 v3 的脈絡化(每題標定場域)其實已經在往拆題那邊走了,只是當時沒意識到這是同一個選擇。

建議寫成明文立場

測驗端傾向拆題(事前消歧,換乾淨資料);判讀端傾向並列(事後留張力,換真實)。

理由:測驗端要算分,歧義會直接污染分數;判讀端不算分,張力可以原樣交還素材主人。

這條若成立,可同時解釋 v3 為何要標場域、以及爻疑為何不強裁——兩個看似無關的決定,其實出自同一條原則的兩端。

四

下一步

  1. 候選一:先跑既有作答資料的四對待雙高分布,再談定義與門檻(未經資料不得寫死門檻)。
  2. 候選二:L1 可即刻試行(報告加一句引導語);L2 / L3 待 G 條款三條明文化。
  3. 設計立場:若認可,寫進解讀憲法或題本 spec 當一條明文原則。
  4. 三條皆不動 B3;任何實作都會產生新題本碼,分數不可與 B3 互比(比照 B1 × B2 × B3 既有規則)。

誠實邊界:本文件為候選,非決議。鄰居的做法並列參照、不做對映——九向度測的是反應風格(多快、多強、多規律),八態測的是功能傾向(開創、承接、行動…),兩者正交。任何「高活動量 ≈ 震」式的對照表都是錯的,會同時損害兩邊的公信力。此處借的只是設計手法,不是內容。
