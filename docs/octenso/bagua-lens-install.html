八態鏡 · 安裝與使用說明

READ THE OPERATION, NOT THE PERSON · 2026-07-16

八態鏡讀的是「運作」——一場會議、一份提案、一段紀錄如何運作——永遠不是「人」。 它有兩種用法:網頁版(貼上就照,零安裝)與 skill 版(裝進你的 Claude,支援檔案、可對話追問)。挑一條路即可。

路線一 · 網頁版(最簡單,推薦先用這個)

  1. 跟 Simon 要一組通行密碼(進站時輸入一次即可)
  2. 打開:https://flow222git.github.io/jte-platform-2026/octenso/bagua-lens.html
  3. 貼上素材(或貼公開網址按「抓取」)→ 選素材類型 → 按「照一下」
  4. 等 1–3 分鐘,報告出來後,記得按「很像/部分像/不太像」送出回饋——鏡子靠這個變準

限制:只吃純文字與公開網址。Word/PDF 請開檔後全選複製、貼上即可。

路線二 · Claude Code(工程師路線)

skill 住在專案裡,clone 下來就自動載入:

git clone https://github.com/flow222git/jte-platform-2026.git
cd jte-platform-2026
claude
觸發語
「用八態鏡讀這份會議紀錄」·「照一下這份 BP」·「透鏡判讀這個檔案」

這條路支援檔案:PDF 直接讀,Word/Excel 會自動抽文字,Google Drive 連結也可以 (需該對話環境已連接 Drive)。

路線三 · claude.ai(手機/網頁版 Claude)

  1. 下載 skill 檔:SKILL.md(點開後另存)
  2. 在電腦上建一個資料夾,命名 bagua-lens,把 SKILL.md 放進去
  3. 把整個資料夾壓縮成 zip
  4. claude.ai → 設定 → 功能(Capabilities)→ 上傳 skill → 選這個 zip
  5. 之後在任何對話說「用八態鏡讀這份」即可

路線四 · 裝到自己電腦全域(所有專案可用)

mkdir -p ~/.claude/skills/bagua-lens
curl -o ~/.claude/skills/bagua-lens/SKILL.md \
  https://raw.githubusercontent.com/flow222git/jte-platform-2026/main/.claude/skills/bagua-lens/SKILL.md

為什麼裝了不用更新

skill 本身不含任何判讀定義——它只指向唯一的判讀依據(states-schema)。 在 repo 外執行時會自動抓 GitHub 上的最新版,所以 schema 進化一次, 所有安裝點下次判讀自動用新版,不會出現各自為政的舊鏡子。

它能照什麼、不照什麼

照得動照不動
會議紀錄(逐字稿/語音轉文字)量表分數、統計表(數字裡沒有話語)
BP/提案、制度文件、對外文案任何「評價一個人」的用途
訪談逐字稿、開放題回覆、觀察筆記排名、選才、錄取建議(直接婉拒)

面試筆記可以照,但會自動降級為觀察模式:只列「已收集/尚無資料的態」與補問建議,不做評價。

八態鏡是 AI 依 states-schema(v0.1,研究假設待考)產生的判讀,每條判定附素材原文引文,請自行核對。 缺席=素材沒給,不等於弱;只診斷不預測;主詞永遠是運作,不是人。 素材與報告不上傳;你按「送出回饋」時只回傳評價與留言。
