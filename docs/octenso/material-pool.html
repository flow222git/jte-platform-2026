〇、入倉三道翻譯規則(所有外部素材一律過)

  1. 主詞換掉:類型語言→分支狀態語言。主詞必須是分支,不是人。 例:「兌分支過度激活時,可能出現迎合、依賴認同」;禁用「這種人會…」。
  2. 因果變邀請:預測句→問句。不做「你接下來會走向哪個狀態」的預測(並列不捏因果)。
  3. 臨床邊緣字眼(焦慮、自我犧牲、躁進…)標待審閱,不直接上線。

出倉另守:鏡子隱喻限量(「不是測驗,而是一面鏡子」只在定位宣言講一次,其他地方用行為示範代替);金句公式一封信/一篇最多一句。

二、素材區

A-4 雅稱 + 一句話(BRIEF 潤稿底稿)原始

  • 開創者(乾)·展行——讓原本不存在的可能開始存在
  • 承接者(坤)·承載——讓開始真正長成
  • 行動者(震)·啟動——打破平衡,使生命重新流動
  • 拓展者(巽)·滲透——真正的改變,不靠力量,而靠持續滲透
  • 沉澱者(坎)·探索——深入未知,找到真正的路
  • 明現者(離)·照見——讓事物真正被理解
  • 喊停者(艮)·定界——停止,不是結束,而是形成新的邊界
  • 交流者(兌)·共鳴——交流讓生命產生新的可能

潤稿備忘:巽、艮兩句是「不是 A,而是 B」句式,兌句「產生新的可能」偏籠統——過 speak-human-tw 時會處理;定案後寫入 BRIEF(bagua-v2-data.js)。

A-3 四系統核心命題問句(報告引言用)已定案·待寫入(第二波)

  • 建構(乾⇄坤):開始如何成為現實?
  • 推動(震⇄巽):改變如何深入系統?
  • 認知(坎⇄離):探索如何形成理解?
  • 調節(艮⇄兌):停下如何形成共好?

撞詞已解(2026-07-14 定案):原「沉澱如何形成共好?」的「沉澱」是坎的主稱呼 (認知系統分支),放在調節系統會誤導;改「停下」直接對應艮的分支動詞「關起門」 與喊停者本義。另認知句的「探索」是坎的雅稱、同系統內使用,不衝突。 A-6 自問句庫若有以「沉澱」指涉艮/停頓的句子,寫入伴讀前比照本則一起處理。

A-7 「今天的整理」信件語料(收尾精神,依主峰分支選一句)已上線(bagua-hybrid-data.js letterSpirit;過 speak-human 潤稿)

底稿(原始)→ 上線版(去「而不是/而非」句式,一封信只選一句):

A-11 失衡/成熟描述 原始·待審閱(本輪不上線)

失衡(入庫前須過規則①主詞換分支+規則③臨床字眼標記):

  • 乾=獨斷、控制、急於求成/坤=過度配合、自我犧牲、沒有主體
  • 震=躁進、三分鐘熱度、反應過度/巽=討好、沒有立場、過度妥協
  • 坎=焦慮、過度分析、停滯/離=表現欲、流於形式、只看表象
  • 艮=固執、封閉、抗拒改變/兌=過度迎合、依賴認同、流於表面

成熟:

二之二、吳怡《易經》理用道體系(2026-07-14 外部素材,四份)

來源:使用者提供的四份文件(吳怡老師《易經》與道家思想的整理)。 學理核對結果:八卦的三爻陰陽配置與六組歸類全部正確,與 canonical 一致: 乾陽陽陽/兌陽陽陰/離陽陰陽/震陽陰陰/巽陰陽陽/坎陰陽陰/艮陰陰陽/坤陰陰陰。

結構發現(可直接用):理/用/道 三爻=能量晶體立方體的三條軸。 晶體以三爻位元座標把八卦放在立方體八角,翻動一爻=沿一條稜邊移動,故初爻(理)/二爻(用)/三爻(道) 恰為立方體的三個方向;四大系統的錯卦對(穿心對角線)=三爻全翻。晶體的三條軸原本沒有名字,這批素材給了。

A-12 理/用/道 三層探問法 原始

三個層次各問一題,判斷偏陽/偏陰,組合成一個卦: - 理(初爻):面對新事物/獨處時的底層心態——「先盤點自己有什麼」(陽)vs「先隱藏觀察、放空聽人」(陰) - 用(二爻):遇阻力/危機時的手腕——「堅持原則推過去」(陽)vs「以柔克剛、退讓沉默」(陰) - 道(三爻):登頂/大權在握時的姿態——「繼續擴張、照耀天下」(陽)vs「不居功、回歸平靜」(陰)

不採用為計分法(結論,2026-07-14):三個二選一 → 把人放進 8 格之一,是分類法不是剖面, 撞到「身分=格局,卦只是峰名」與 A-5 定位宣言「不是人格分類系統」;且量測脆弱—— 翻一個爻,巽即變乾,無雜訊容忍(對照:現制每態 3 題+NOISE=8)。 原文「探測潛意識」的宣稱亦不採用:輸入是主觀自評,只能反射自我感覺(MODEL.md), 誠實印章背不動這個宣稱。

採用方向:①爻位=題庫池的新槽位維度(態 × 爻位),讓同一態能從三個深度出題 (底層心態/手腕/終極追求),補現行 28 題全為「行為微場景」單一深度之不足 → 進 v3 題本(B3)工作。 ②三個提問可加入伴讀自問句庫(A-6)當深探問句,零計分零分類。

A-13 八卦死角與應對之道(留有餘地)原始·待翻譯

每卦的過亢/不足死角與制衡方向(以相反爻性補位): - 乾:過剛易折 → 刻意加入退讓柔軟,留有餘地 - 坤:一旦生居功私心即失厚德 → 貫徹無私,成就他人 - 震:內在動能盲目暴衝 → 用(二爻)保持陰柔彈性,不硬碰硬發洩 - 巽:太早出頭、基礎未穩即大張旗鼓 → 守初爻陰柔,低調潛伏待時 - 坎:險境中隨波逐流失原則 → 緊抓中爻「維心」(誠信與堅持) - 離:過度自我、單打獨鬥而熄滅 → 用(二爻)把自我虛掉,依附團隊 - 艮:積累期沉不住氣、提早爆發 → 落實理與用的陰柔,剛毅留到最高境界 - 兌:內在動能過強而外顯壓迫 → 修練最外層(道)如沐春風的柔和

用途:升級能格(COST)的 over/under 建議文案——我們本就有 aOver/aUnder 槽位, 吳怡的「以相反爻性制衡、留有餘地」是同一形狀但更好的說法。 入庫前須過規則①(主詞換分支,不是「這種人會…」)。 「用心如鏡、不取不捨」(莊子/禪宗)與 A-2 恢復流動同一姿態,可補強伴讀語氣憲章—— 但只作為伴讀自己的姿態,不作為對症狀給的建議(見 A-14)。

A-14 心理症狀 × 卦象死角對應 原始·臨床·不入產品 ⛔

原文將憂鬱/恐慌/焦慮/強迫症對應到卦象失衡並給出「八卦處方」。

不入產品(2026-07-14 判定),原因三條,任一條即足以擋下: 1. 診斷語言:憂鬱症/恐慌症/強迫症為臨床分類,我們無資格指認。 2. 治療語氣:「處方/解藥/化解」越過「這是自我探索工具,不是心理衡鑑、諮商或治療」的界線 (該界線句已寫在 hello[2]、伴讀 LLM 守則、Worker 端)。 3. 因果句:「坤卦失衡→憂鬱」直接違反 C1 並列不捏因果,亦違反伴讀守則 「不要替我編報告裡沒有的因果機制」。

風險場景(這才是真正要防的):正在憂鬱的使用者讀到「你是坤卦型憂鬱,要引入乾卦陽剛動能」, 把它當處置而不去求助。危機攔截(1925/1995/1980)存在的理由就是我們知道低谷中的人會來。

保留於倉內僅供內部理解模型,任何文案、伴讀守則、報告內容一律不引用。 若未來要碰,前置條件是心理師/臨床心理背景者正式審閱並掛名,不是潤稿能解決的問題。

A-15 八卦人際應對(虛己以應物)原始·待翻譯

原文給出「遇到八種類型的人」各自的應對之道,核心機制為陰陽相濟: 對方極端「有(剛)」則以「無(柔)」承載轉化,對方極端「無(弱)」則以適度「有」引導; 互動前先「虛己」——把自己的成見拉掉,觀察對方狀態再反應(太極接手)。

翻譯要求(入合盤頁前必做): 1. 去評斷語:原文的「心思隱暗、動用詐術」「自視甚高」「固執己見、防備心重」「帶有目的性」 等形容詞一律不用——我們只測自陳,對「對方」沒有任何資料,從外部給人貼負面標籤 會把自我之鏡變成刻板印象工具。 2. 主詞轉回讀者自己:從「遇到 X 型人,對方是…」改寫為 「當場上出現 X 的能量時,你可以補上什麼」——虛己以應物本來就是關於自己的功夫, 這樣改既保住原意,也守住「不診斷不在場的第三人」。 3. 遵守二-4 合盤呈現原則:只對照不速配、不排相性分數、差異用中性語言。

用途:二-4 合盤頁與團隊圖的內容底稿(排在 v2 試測之後); 「虛己、先觀察再反應」與伴讀「先接住再展開」同一姿態,可互相印證。
