〇、入倉三道翻譯規則(所有外部素材一律過)

  1. 主詞換掉:類型語言→分支狀態語言。主詞必須是分支,不是人。 例:「兌分支過度激活時,可能出現迎合、依賴認同」;禁用「這種人會…」。
  2. 因果變邀請:預測句→問句。不做「你接下來會走向哪個狀態」的預測(並列不捏因果)。
  3. 臨床邊緣字眼(焦慮、自我犧牲、躁進…)標待審閱,不直接上線。

出倉另守:鏡子隱喻限量(「不是測驗,而是一面鏡子」只在定位宣言講一次,其他地方用行為示範代替);金句公式一封信/一篇最多一句。

二、素材區

A-4 雅稱 + 一句話(BRIEF 潤稿底稿)原始

  • 開創者(乾)·展行——讓原本不存在的可能開始存在
  • 承接者(坤)·承載——讓開始真正長成
  • 行動者(震)·啟動——打破平衡,使生命重新流動
  • 拓展者(巽)·滲透——真正的改變,不靠力量,而靠持續滲透
  • 沉澱者(坎)·探索——深入未知,找到真正的路
  • 明現者(離)·照見——讓事物真正被理解
  • 喊停者(艮)·定界——停止,不是結束,而是形成新的邊界
  • 交流者(兌)·共鳴——交流讓生命產生新的可能

潤稿備忘:巽、艮兩句是「不是 A,而是 B」句式,兌句「產生新的可能」偏籠統——過 speak-human-tw 時會處理;定案後寫入 BRIEF(bagua-v2-data.js)。

A-3 四系統核心命題問句(報告引言用)已定案·待寫入(第二波)

  • 建構(乾⇄坤):開始如何成為現實?
  • 推動(震⇄巽):改變如何深入系統?
  • 認知(坎⇄離):探索如何形成理解?
  • 調節(艮⇄兌):停下如何形成共好?

撞詞已解(2026-07-14 定案):原「沉澱如何形成共好?」的「沉澱」是坎的主稱呼 (認知系統分支),放在調節系統會誤導;改「停下」直接對應艮的分支動詞「關起門」 與喊停者本義。另認知句的「探索」是坎的雅稱、同系統內使用,不衝突。 A-6 自問句庫若有以「沉澱」指涉艮/停頓的句子,寫入伴讀前比照本則一起處理。

A-6 伴讀自問句庫(邀請式,絕不做狀態預測)已上線(worker.js OCTENSO_SYSTEM)

  • 開始之後,如何真正長成?
  • 成熟之後,何時再次啟動?
  • 啟動之後,如何深入系統?
  • 影響之後,還有哪些未知?
  • 探索之後,看見了什麼?
  • 理解之後,需要停下來想什麼?(原「需要沉澱什麼?」,比照 A-3 除撞詞)
  • 停下之後,如何分享?(原「沉澱之後」)
  • 交流之後,新的可能是什麼?

撞詞已解:兩句原用「沉澱」指涉艮的停頓,與坎主稱呼相撞,改「停下」。 寫入伴讀 LLM 守則,標明「只是邀請,不預測他會走去哪」(並列不捏因果)。

A-7 「今天的整理」信件語料(收尾精神,依主峰分支選一句)已上線(bagua-hybrid-data.js letterSpirit;過 speak-human 潤稿)

底稿(原始)→ 上線版(去「而不是/而非」句式,一封信只選一句):

  • 乾:每天創造一個新的開始 → 你最亮的地方是「開始」——記得,每天都能重新開一個局。
  • 坤:學會說「不」,讓承載有界線 → 學會說「不」,你的承載才有界線。
  • 震:把速度轉化為節奏 → 把橫衝的速度,慢慢轉成走得久的節奏。
  • 巽:在柔軟中保持自己的方向 → 保持柔軟,但別弄丟自己的方向。
  • 坎:相信流動,而不是追求完全控制 → 相信流動,不必事事都要掌控。
  • 離:追求真實,而非只是清楚 → 先求真實,再求清楚。
  • 兌:分享真實,而非追求喜歡 → 分享真實,別只想著討喜。
  • 艮:停止是為了再次流動 → 停下,是為了能再次流動。

letterClose 併入 A-2 恢復流動原則:「真正要練的,不是把哪一股衝到滿,是讓卡住的地方重新動起來。」(整封信的唯一一句「不是A是B」)

A-8 T3 四組雙峰試點 · 場域底稿(兩兩相疊寫「雙分支同強」)原始

  • 乾:創業、策略、創新、開局/坤:營運、制度、服務、培育
  • 震:變革、專案啟動、危機突破/巽:文化、品牌、教育、組織變革
  • 坎:研究、分析、風險管理、策略/離:設計、教育、顧問、內容創作

A-11 失衡/成熟描述 原始·待審閱(本輪不上線)

失衡(入庫前須過規則①主詞換分支+規則③臨床字眼標記):

  • 乾=獨斷、控制、急於求成/坤=過度配合、自我犧牲、沒有主體
  • 震=躁進、三分鐘熱度、反應過度/巽=討好、沒有立場、過度妥協
  • 坎=焦慮、過度分析、停滯/離=表現欲、流於形式、只看表象
  • 艮=固執、封閉、抗拒改變/兌=過度迎合、依賴認同、流於表面

成熟:

  • 乾=開始,也懂得交棒/坤=承載而不失去自己
  • 震=行動有節奏,而非衝動/巽=柔軟而有中心
  • 坎=能面對不確定而不失方向/離=照亮別人,也照亮自己
  • 艮=知道何時停止/兌=真誠分享,而非討好

附註:翻譯後的失衡語彙另有企業端用途——低心理安全偵測結果給 HR 的回饋話術庫。先入庫標記,不動工。
