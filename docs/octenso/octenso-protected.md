# 八態能格 · 校稿保護清單(speak-human-tw 專用)

v0.1 · 2026-07-14(依同日 app 討論定案總表 C-17)
用法:任何文案過 speak-human-tw(或其他潤稿流程)之前,先鎖本清單再改;
清單內的內容**原封不動**,只能調前後銜接。

## 一、全站術語(防「刻意換詞循環」誤殺——重複出現是規格,不是 AI 味)

- 品牌與工具名:八態能格、練息場、問易、月照鏡、能量晶體、心情溫度計、對境耗能、AI 伴讀/八態伴讀
- 先者後卦稱呼(全套,含括號形式):開創者(乾)、承接者(坤)、行動者(震)、拓展者(巽)、沉澱者(坎)、明現者(離)、喊停者(艮)、交流者(兌)
- 雅稱(副標):展行、承載、啟動、滲透、探索、照見、定界、共鳴
- 四大系統名:建構、推動、認知、調節(+「○○系統」形式)
- 分支動詞(A 組,已凍結):定方向、接住人、直接動手、先鋪路、收著想、說出來、關起門、找人聊
- 狀態語彙:優勢分支、雙分支同強、低載運轉、輪流上場、中正、亢·過用、潛·不足
- 量尺與碼:B1/B2/M 碼、篤定/兩可、六級(非常像…完全不像)

## 二、誠實註腳與制式句(責任邊界,不是 AI 味,不刪不改寫)

- 「僅借概念結構,不宣稱生理對應」(自律神經借喻註腳)
- 「v0.1 研究假設·待考」及各版本誠實印章句(B.HONEST)
- 「描述位移,不解釋原因、不評好壞」「測量誤差」「快照非定義」等邊界句
- 「作答只存在這台裝置上、不上傳」隱私句
- 危機求助文案全段與電話(1925/1995/1980/119)——一字不動
- 「B1/B2 分數不可互比」「不能直接相減」規則句

## 三、結構性格式(功能,不適用「降格式」規則)

- 三層解讀架構與報告分段揭示結構(峰→系統→水平→二選一對照)
- 音量條標籤、狀態分區平面的軸標與區名(同強/低載)
- 逐段核對選項句:「很像/部分像/不太像」;回應語「收到,謝謝你。」
- 九面向表格、術語對照表等真正多維度對照表
- 題目選項量尺文字(OPTS/FREQ_OPTS/FC_OPTS/CTXD_SCALE/CTXD_INTENSITY)——改了就毀量尺等值性,潤稿禁區

## 四、既定風格容忍(house style,不視為 AI 痕跡)

- 全站中文標點採半形「,」「?」「(」慣例——全域決定,不在單篇潤稿中改
- 「——」破折號是版面語言的一部分;僅當**同一句出現兩個以上**才處理
- 語氣憲章:心理師不是服務員——少致謝、多陪伴;暫定語;先接住再展開

## 五、校對工作流(C-20/21)

- 站位:定稿前最後一站。BRIEF、題幹、信件語料、T3 文案出貨前都過一遍;情境判定多為「辦公文書/報告」力度。
- 模式:互動改稿用預設兩輪確認(先列清單等勾選);接進自動化產線時選「跳過確認、事後摘要」,用 git diff 回溯——保護清單與保真回讀不豁免。
- 伴讀 LLM 守則負面清單(C-18,寫入 Worker 守則時取用):罐頭同理心(「我完全理解你的感受」→用具體下一步取代)、說教式深度腔(說到底/本質上/真正的問題在於)、金句公式(X 是 Y 的 Z;一封信最多一句)。
- 鏡子隱喻限量(C-19):「不是測驗,而是一面鏡子」只在定位宣言講一次;報告內文與行銷文案不重複宣稱,用行為示範代替。
