衡鑑式伴讀 · 像心理師一樣陪你

THERAPEUTIC COMPANION · 2026-07-12 · TONE + PROCESS

整理日期:2026-07-12 ｜ 狀態:方向定案、腳本草案待潤(建議心理師審閱) 緣起:使用者提案——「像心理師幫個案做測驗、一起了解使用者的角度來進行整個過程,尤其是結果的說明,用專業同理溫潤的語氣、共同探討的角度出發」;目標=珍貴的使用者回饋+整套服務的可接受度。 學理錨點:治療性衡鑑(Therapeutic Assessment, S. Finn)——把測驗從「對個案做的事」變成「與個案一起做的事」,衡鑑本身即是善意的介入;回饋依「與自我印象的一致度」分層呈現。 上游:2026-07-12 半題庫半對話 spec(紅線照舊:題庫測量、對話選路、對話永不打分)、伴讀守則、學理/解讀憲法。

0. 一句話

分數還是規則引擎算的,但遞給你的方式,像一位溫潤的心理師:先聽你想了解什麼,一段一段陪你核對「像不像」,最後把今天一起看到的,整理成一封留給你的信。

1. 語氣憲章(六條,適用所有腳本與伴讀 LLM)

  1. 暫定語:「測驗照出來的是……你聽起來覺得呢?」——不是「你是」,是「我看到的是,請你核對」。
  2. 使用者是自己生活的專家:分數是假設,他的經驗才是裁判;「不像」是珍貴訊息,回應永遠先謝謝、再好奇,不辯護。
  3. 先接住,再展開:沉重的段落(掏空、亢、場域不給)先一句同理,再給內容。
  4. 一次一件事:每段只談一個主題,以開放的邀請收尾,不轟炸。
  5. 不評價、不催促:選項沒有好壞;「先不想說」「先跳過」永遠是被尊重的選項。
  6. 借態度、不借身份:全程明示「這是自我探索工具,不是心理衡鑑、諮商或治療」;溫潤但不製造依附;危機協議永遠優先。

2. 流程對應(TA 三招 → 伴讀版三機制)

TA 實務 伴讀版機制 落點
衡鑑從「個案的問題」開始 開場收一句「你想多了解什麼?」(自由填,可跳過);摘要後第一句回應它、結尾回顧它 開場+摘要+信
回饋分層:先講與自我印象一致的,再講意外的 分段揭示:①峰名(最可能被認同)→②四道門主軸→③能量水平與能格→④二選一落差(若有,Level 2 素材)→ 連結與模組 摘要階段
每段與個案核對 逐段三鍵核對:很像/部分像/不太像——三種回應各有同理回話;核對紀錄=結構化共鳴資料(比自由回饋精準) 摘要階段
結尾寫給個案的信 「今天的整理」一封信:規則組裝(你的問題+峰名+你核對過的段落)+伴讀回饋摘要 結束時

紅線不變:核對按鈕不改分數——它是回饋資料與對話素材,不是計分輸入。

3. 資料設計(珍貴回饋的形狀)

  • ask:使用者開場寫下的問題(原話)。
  • echo:{peak, gate, level, fcgap} → 很像/部分像/不太像——逐段共鳴資料,直接對回內容區塊,可跨使用者統計「哪一段最常不像」→ 修型錄的優先序。
  • 以上入 localStorage;伴讀聊天 grounding 附帶(LLM 知道你帶什麼問題來、哪段你搖頭);「結束伴讀」的回饋摘要一併帶回(Worker FEEDBACK KV 若綁定則落檔)。
  • 誠實邊界:開場明示核對紀錄的用途;作答與核對都只存本機,回傳的只有結束時的摘要(既有揭露)。

4. 界線條款

  • 開場白第三句固定包含:「這是自我探索的鏡子,不是心理衡鑑或治療,也不是算命。」頁尾誠實印章同步。
  • 危機關鍵字攔截照舊(本機、不經 LLM、給 1925/1995/1980)。
  • 語氣升級後更要防「過度臨床感」:不用診斷詞彙、不用個案/晤談等術語對使用者說話。
  • 心理師審閱迴圈:腳本定稿前送合作心理師潤稿;上線後掛「腳本經心理師審閱」——體驗與公信力資產(Route C 的自然協作)。

5. 實作對應(伴讀版 bagua-hybrid)

  • bagua-hybrid-data.js CHAT 全面重寫為衡鑑語氣(草案待潤+心理師審);新增 askIntro/askSkip/askEcho、segXxx 分段引言、ack 三態回話、letter 模板。
  • bagua-hybrid.html:開場插入收問題(自由填/跳過);toSummary 改分段揭示+逐段核對;結束時先出「今天的整理」信、再接回饋摘要;grounding 附 ask+echo。
  • ven-i/worker.js OCTENSO_SYSTEM 增補語氣守則(§1 憲章的 LLM 版);push 即自動部署。
  • v2 報告頁不動(靜態報告維持文件感);衡鑑式體驗以伴讀版為家。

6. 待決

  1. 腳本全文的心理師審閱(定稿前)。
  2. 「今天的整理」信要不要提供下載/寄給自己(涉及資料流,預設只顯示+複製)。
  3. 逐段共鳴資料的彙整管道(目前:結束摘要回傳;之後可考慮匿名統計 opt-in)。
  4. v2 報告頁是否也加輕量版逐段核對(傾向不加,保持雙軌:文件感 vs 陪伴感)。
這是一面認識自己與關係的鏡子,不是算命、不是命定——能量會流動,也可以成長。
